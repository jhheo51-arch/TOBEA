## 확인한 것
자동 검증 22개: 계산과 CSV 처리 13개, AI 입력 최소화·제안과 검토의 두 호출·검토 보류·존재하지 않는 근거 차단·미설정과 인증 실패·잘못된 인원·비밀 파일 차단·외부 주소 요청 차단과 한국어 전달·설정 파일 다시 읽기 9개.

AI 시험은 외부 응답을 코드 안의 시험 응답으로 대체했습니다. 자동 검증 결과는 실제 API 사용이나 실험 성과가 아닙니다. 별도 실제 연동 시험에서는 가상 자료로 총 네 번의 API 호출(두 번의 생성·검토 흐름)을 실행해 검토 보류·검토 통과를 확인했습니다. 브라우저에서는 키가 없는 상태에서 목표·동의를 입력해도 실행이 차단됨과 익명 집계 미리보기를 확인했습니다. 실제 내려받은 JSON 보관 내용을 붙여넣어 복원·이전 작업 보존도 확인했습니다. 기존 v02의 가상 행동 자료 집계·가설 수정·이전 분석 복원은 별도 검증했습니다.

## 남은 실제 확인
Codex의 기능 시험에서 실제 호출 성공, 세 가설의 근거 표시·검토 결과·기획 반영·이전 기획 보존을 확인했습니다. 참가자의 본인 목표에 따른 직접 사용과 최종 판단 확인은 남아 있습니다. 실제 사용자 자료와 수요, 개선 효과는 검증하지 않았습니다. 파일 선택 자동화는 Chrome 확장의 접근 권한 제약으로 완료하지 못했으며 붙여넣기 경로로 확인합니다.

## GitHub 제출
이 폴더의 소스·빈 `.env.example`·문서·시험 파일만 제출합니다. `.env`, 원본 사용자 자료, 다운로드한 분석 보관 파일은 공개하지 않습니다. 워크샵 전체 폴더와 작업일지도 포함하지 않습니다.

제출자는 README와 AGENT_DESIGN을 읽고 본인의 선택 이유를 기획 보고서에 작성해야 합니다. GitHub 저장소 URL을 강사가 마련한 제출 칸에 직접 등록합니다. PPT는 필수가 아닙니다. 발표는 문제 → 자료 기준 → 개선 후보 → 본인 판단 → AI 역할과 검증 한계 순서가 적합합니다.
