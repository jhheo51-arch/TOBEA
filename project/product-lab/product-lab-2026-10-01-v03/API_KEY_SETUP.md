# OpenAI API 키 설정 안내

API 키는 프로그램이 OpenAI를 사용할 때 제시하는 비밀 인증값입니다. 채팅에 보내거나 GitHub에 올리지 마세요.

1. [OpenAI API 키 페이지](https://platform.openai.com/api-keys)를 열고 본인 계정으로 로그인합니다. 사용할 프로젝트를 선택하고 새 비밀 API 키를 생성합니다. 로그인 화면 내부의 버튼 위치는 이 문서에서 확인하지 않았습니다.
2. 생성한 키를 복사해 실습 폴더의 `project/product-lab/.env`를 Codex 파일 편집기에서 엽니다. `OPENAI_API_KEY=` 오른쪽에 키를 붙여넣고 저장합니다. 따옴표 없이 한 줄에 입력하면 됩니다. 이 파일은 GitHub에서 제외됩니다.
3. 웹서비스의 ‘설정 다시 확인’을 누릅니다. ‘실제 호출 준비됨’이 보이면 목표를 입력하고 전송·비용 확인 항목을 선택한 뒤 실행합니다. 준비 표시는 키의 유효성이나 모델 권한을 검증한 결과가 아닙니다. 최초 호출 성공으로 확인합니다.

계정의 API 결제·사용 가능 잔액·모델 접근 권한은 본인이 확인해야 합니다. [공식 시작 안내](https://developers.openai.com/api/docs/quickstart)와 [운영 지침](https://developers.openai.com/api/docs/guides/production-best-practices)을 참고하세요. 비용 설정과 결제는 Codex가 대신하지 않습니다.

`.env` 설정값:

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-6-luna
PORT=4197
```

GitHub에서 처음 내려받은 경우 `.env.example`을 복사해 `.env`라는 이름으로 저장한 뒤 키를 입력합니다. 로컬 실습에서는 `project/product-lab/.env`를 사용합니다. 서버는 상위 폴더의 `.env`를 우선 읽고, 없으면 서버와 같은 폴더의 `.env`를 읽습니다.

키와 모델은 ‘설정 다시 확인’ 및 실행 요청 때 파일을 다시 읽습니다. 주소 번호인 PORT를 바꾼 경우에는 서버를 재시작해야 합니다. 기본 모델은 [공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-6-luna) 기준으로 지정했습니다. 계정에서 사용하지 못하면 사용 가능한 구조화 출력 지원 모델로 바꿉니다.

인증 오류: 키 상태를 확인합니다. 사용 한도 오류: 결제·잔액·요청 한도를 확인합니다. 응답 미완성: 재실행 여부를 직접 결정합니다. 자동 재시도하지 않으므로 실패한 요청도 비용이 발생할 수 있습니다.

`.env` 자체가 파일 내용을 암호화하는 금고는 아닙니다. 이 컴퓨터에 접근 가능한 사람이 읽을 수 있습니다. 유출되면 키를 폐기하고 새로 발급합니다. 공개 서버로 배포할 때는 서버 제공 업체의 비밀 설정 기능으로 전달해야 합니다.
