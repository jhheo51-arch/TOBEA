# 구자욱 편 질문 검토와 근거 카드

작성일 2026-10-03. 기존 analysis.md와 observed-data.json, calculate.py를 바탕으로 제작 구조를 적용했습니다. 외부 출처는 앞선 2026-10-03 조사에서 확인한 자료를 재사용했습니다. 이번 작업에서 웹 원문을 새로 조사하거나 독립 재검증하지 않았습니다. 이후 발행 전에는 변동 가능한 누적 기록을 다시 확인해야 합니다.

## 질문 검토 결과

| 항목 | 검토 |
|---|---|
| 사용자 질문 원문 | 만약 그 순간 구자욱이 2루로 뛰지 않았더라면 |
| 대상 | 앞선 분석의 대상인 2026-09-30 한화전. 2024-10-15 LG전은 비교 사례 |
| 변경할 선택 | 해당 장면에서 2루 진루를 시도하지 않음 |
| 아직 확정하지 않은 조건 | 1루에 안전하게 멈출 수 있었는지, 이후 무부상과 정상 출전까지 가정하는지 |
| 비교할 결과 | 진루 판단의 가치와 이후 타선 공백을 나누자는 AI 제안. 우승 여부까지 확장할지는 사용자 결정 |
| 분석 시점 | 당시 선택의 판단과 사후 공백 설명을 분리 |
| 확보 자료 | 사건 보도, KBO 누적 타격 기록, 재계산 코드 |
| 자료 공백 | 해당 경기 전체 플레이, 당시 점수와 선수 상태, KBO 상황별 득점 기대값, 해당 타구 진루 성공 가능성 |
| 진행 판정 | 조건부 가능. 사실 정리와 관측 성적 비교는 가능하나 진루의 순이익·부상 회피·추가 승수는 산출 불가 |

원래 질문을 유지합니다. ‘안 뛰었다면 무조건 안 다쳤다’를 질문 속 확인된 전제로 넣지 않습니다. 좁힌 분석 질문은 ‘한 베이스의 추가 가치와 향후 출전 가능성을 어떻게 비교할까’이며 사용자 문제 정의를 대체하는 확정 문장이 아닙니다.

- 미확인: 구단 원문 공지, 추후 검사 결과와 실제 복귀일.

### E07 구자욱 공격 성적의 구성 변화

- 반대 근거·대안: 같은 OPS라도 득점 환경·상황별 기여와 미래 능력이 같다는 뜻은 아님.
- 미확인: 보정된 시즌 간 가치 비교.
- 판정·표현: 산술 확인됨. ‘홈런 빈도 감소와 출루율 상승이 함께 관측됐다’로 사용.

### E10 두 선수의 성적 격차

- 주장·종류: 출루율 차이 14.1%포인트, OPS 차이 .360. 계산.

- 확인 범위: (.458-.317)×100=14.1, (.458+.581)-(.317+.362)=.360. 반올림된 공시 비율 사용.

- 판정·표현: 산술 확인됨. ‘관측 기록 차이’로 사용하며 손실 득점·승수로 환산하지 않음.

### E11 추가 진루의 가치 계산 설계

- 주장·종류: 2사 2루와 2사 1루의 득점 기대값 차이가 비교 기준이 될 수 있음. 방법론·분석 제안.
- 출처: [FanGraphs RE24](https://library.fangraphs.com/misc/re24/), [비도루 주루 가치 설명](https://library.fangraphs.com/offense/ubr/).
- 확인 범위: 주자·아웃 상황별 이닝 잔여 평균 득점이라는 정의. 다른 주자 없음, 실패 시 이닝 종료라는 단순 조건에서 pR2와 R1 비교. R2>0일 때 손익분기 p=R1/R2.
- 반대 근거·대안: 이 단순식은 부상과 미래 경기, 점수 차에 따른 승리 가치를 포함하지 않음.
- 미확인: 해당 KBO 환경의 R1·R2와 해당 타구의 p. 미국 리그 수치를 가져와 대입하지 않음.
- 판정·표현: 계산 구조만 제안. 실제 이익이나 적정 진루 성공률 산출 완료가 아님.

- 반대 근거·대안: 실제 출전 선수와 타석 수가 달라지면 그 변화분은 포함 가능.
- 미확인: 전체 타선의 실제·비교 타석 배분.
- 판정·표현: 조건부 방법론 판단. 실제 중복 계산이 발생했다고 주장하지 않음.
