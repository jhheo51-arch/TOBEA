# Whatif 콘텐츠 저장 규칙

사용자 지정 규칙입니다. Whatif는 기획 → 분석 → PM적 사고 → 결과 도출의 흐름으로 진행합니다. 가정별 결과 추정과 교훈 작성은 사용자가 담당합니다.

- 새 콘텐츠를 시작할 때마다 이 폴더 아래에 해당 콘텐츠만의 별도 폴더를 만듭니다.
- 기본 이름은 `주제-YYYY-MM-DD-v01`입니다. 생성 전에 같은 이름이 있는지 확인하고, 있으면 다른 버전 번호를 사용합니다.
- 해당 콘텐츠의 원고, 사실 확인 자료, 지표 정의, 분석 데이터, 계산 코드, 시각화는 모두 그 콘텐츠 폴더 안에 저장합니다. 여러 콘텐츠의 결과물을 섞지 않습니다.
- 같은 콘텐츠를 이어 작업하면 기존 콘텐츠 폴더를 확인하고 이어갑니다. 수정 결과는 새 파일명으로 보존하거나 새 버전 폴더를 사용합니다. 기존 파일 덮어쓰기는 최상위 AGENTS.md 규칙을 따릅니다.
- 현재 구자욱 편의 전용 폴더는 `gu-jawook-2026-10-03-v01/`입니다. 이미 자료가 있으므로 중복 폴더를 만들거나 복사하지 않습니다.
- Whatif 전체 기획서와 이 공통 규칙만 Whatif 폴더 바로 아래에 둡니다.
- 작업일지는 TOBEA 최상위 `작업일지.md` 하나에만 기록합니다.
