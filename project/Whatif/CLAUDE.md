# Whatif 작업 안내

이 폴더는 브런치 콘텐츠 제작 프로젝트입니다. 서비스·앱 구현은 요청 범위가 아닙니다. 한국어 존댓말로 설명합니다.

## 먼저 읽을 문서

1. [최신 PRD](PRD-2026-10-03-v03.md)
2. [리서치 검증 임무](<agent mission.md>)
3. [콘텐츠 저장 규칙](AGENTS.md)

이전 PRD.md와 v02는 보관본입니다. 현재 작업 기준은 v03입니다.

## 역할과 순서

사용자가 직접 문제 정의 → AI 질문 검토·사실 검증 → AI 지표 분석 → 사용자 가정·해석 → AI 반론 검토 → 필요한 그래프 → 사용자 최종 글 완성.

AI는 단일 리서치·검증 역할을 수행합니다. 사용자의 가정별 결과, 교훈, 최종 판단을 대신 작성하지 않습니다. 사용자 해석이 없으면 반론 검토는 입력 대기입니다. 기존 자료 재사용과 새 원문 검증을 구분합니다.

## 도구에 종속되지 않는 실행

스킬 호출 문법을 지원하지 않는 환경에서는 아래 파일을 직접 읽고 절차를 수행합니다. Codex 플러그인 설치나 별도 API 키는 이 문서 기반 작업의 필수 조건이 아닙니다. 사용 중인 도구의 웹 접근·파일 접근 권한은 실제로 확인합니다.

- [리서치 진입점](../../.agents/skills/whatif-research/SKILL.md)
- [사실 확인](../../.agents/skills/whatif-fact-check/SKILL.md)
- [지표 분석](../../.agents/skills/whatif-metrics/SKILL.md)
- [요청 시 질문 제안](../../.agents/skills/whatif-questions/SKILL.md)

웹 검색이 없으면 제공된 자료만 분석하고 새 검증을 했다고 말하지 않습니다. 시각화 플러그인이 없으면 확인된 수치로 표나 간단한 그래프를 작성합니다. 출처·단위·기간·관측/추정 구분을 유지하고, 가능한 도구가 없으면 그 한계를 알립니다.

## 현재 이어갈 편

[구자욱 검토 패키지](gu-jawook-2026-10-03-v01/review-package-2026-10-03-v01.md)를 읽습니다. 질문 검토와 근거 카드 14개가 있습니다. 사용자 가정·해석은 아직 제출되지 않았습니다. 자료는 2026-10-03 조사 기준이며 실시간 갱신 자료가 아닙니다. 새로운 사실 주장이나 발행 준비 때는 출처를 다시 확인합니다.

계산 재현은 저장소 최상위에서 다음 명령으로 가능합니다.

```text
python -X utf8 project/Whatif/gu-jawook-2026-10-03-v01/calculate.py
```

계산 성공은 저장된 수치의 산술 일관성 확인이며 원출처 진위나 인과관계 검증과 다릅니다.

## 저장

새 콘텐츠마다 Whatif 안에 별도 폴더를 만듭니다. 기존 편은 그 폴더에 새 파일명으로 이어가며 이전 결과를 보존합니다. 진행 기록은 저장소 최상위 작업일지.md 하나에만 덧붙입니다. 파일이 없다면 그 위치에 새로 만듭니다. 개인 자료·인증값은 기록하거나 공개하지 않습니다.
