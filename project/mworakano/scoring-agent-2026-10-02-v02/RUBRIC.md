# Speakday 채점표 v02 · 토익스피킹 기준 중심

작성일: 2026-10-02. 상태: 구현용 초안, 실제 음성·전문가 검증 전.

## 1. 이번 버전의 결정

- 목표는 오픽 말하기 성적 향상이며, 평가의 중심은 사용자가 선택한 **토익스피킹** 기준이다.
- AI 공급자는 **Gemini**다. 무료 사용량은 실제 프로젝트에서 확인하며 무제한으로 가정하지 않는다.
- v01의 ILR 중심 종합 판단, 8개 항목 0~4점, T/D 점수를 현재 채점에 사용하지 않는다. ILR·CEFR·IELTS를 추가 점수 체계로 혼합하지 않는다.
- 이 문서와 같은 폴더의 [AGENT.md](AGENT.md)가 현재 기준이다. 이전 문서는 보관본이다.
- 공식 기준의 공개 설명을 참고한 개인 학습용 적용이다. 공식 원문 표·기출문제·음성 샘플을 재배포하지 않는다. 창작 예시는 공식 점수가 붙은 실제 답변이 아니다.

## 2. 공식 시험에서 확인한 구조

ETS 응시자 안내서 15~24쪽을 확인했다. 공식 구조를 간단히 요약하면 다음과 같다.

| 공식 문항 유형 | 문항 점수 구조 | 주요 평가 관점 |
|---|---|---|
| 문장 읽기 | 발음 0~3, 억양·강세 0~3을 각각 평가 | 소리의 이해 가능성, 읽는 방식 |
| 사진 설명 | 0~3 | 사진 내용과 말의 전달 |
| 질문 응답 / 제공 정보 기반 응답 | 0~3 | 답변의 관련성·완성도·적절성, 정보 정확성 |
| 의견 말하기 | 0~5 | 입장과 뒷받침, 연결된 설명과 전달 |

언어 판단에는 발음, 억양·강세, 문법, 어휘, 내용 연결이 관여한다. 각 관점을 임의 가중치로 더해 공식 문항 점수를 만드는 방식으로 구현하지 않는다. 공식 시험의 전체 환산점수 0~200을 연습 답변 몇 개로 계산하지 않는다.

출처: [ETS TOEIC Speaking & Writing Examinee Handbook](https://www.ets.org/content/dam/ets-org/fr/pdfs/toeic/toeic-speaking-writing-examinee-handbook.pdf).

## 3. Speakday의 문제 유형 연결

아래 연결은 Speakday 설계 결정이며 ETS가 승인한 대응표가 아니다. 질문 생성 시 유형과 요구사항을 먼저 고정한다.

| 연습 유형 | 내부 식별값 | 적용 점수 | 적용 범위 |
|---|---|---|---|
| 선택한 관심사 질문에 답하기 | response | 0~3 | 질문 응답 관점 적용 |
| 경험 서술·과거와 현재 비교 | opic_extended_response | 0~3 | 오픽형 확장. 사건 순서·변화·이유를 질문별 요구사항으로 지정 |
| 상대에게 정보 질문하기·문제 상황 해결 | opic_roleplay | 0~3 | 오픽형 확장. 묻기·대안 제시·확인 등 요구 행동을 먼저 지정 |
| 뉴스에 대한 의견 말하기 | news_opinion | 0~5 | 기사 읽기까지 포함한 확장. 영어 의견의 전달을 평가 |
| 일반 의견 말하기 | opinion | 0~5 | 입장과 설명을 중심으로 평가 |

사진 설명과 문장 읽기는 현재 사용자가 요청한 필수 학습 흐름에 추가하지 않는다. 추후 추가한다면 공식 문항 유형에 맞는 별도 처리와 자료를 준비한다. 특히 질문 읽어주기는 사용자의 문장 읽기 시험과 다르다.

## 4. 문항 수준 판정

다음 짧은 판정표는 공식 표의 전재가 아닌 학습용 요약이다. 전체 발화 증거로 판단하며, 세부 영역 점수의 평균으로 결정하지 않는다.

| 응답형 점수 | 판단 방향 |
|---|---|
| 3 | 질문에 충분히 답하고 전달이 명확함 |
| 2 | 답변은 가능하지만 내용 누락·부정확성·전달상의 한계가 있음 |
| 1 | 필요한 내용을 제대로 전달하기 어려움 |
| 0 | 유효한 시험 응답으로 볼 내용이 없음 |

| 의견형 점수 | 판단 방향 |
|---|---|
| 5 | 입장과 근거가 충분히 이어지며 언어·음성 전달이 안정적임 |
| 4 | 입장을 뒷받침하지만 설명이나 전달에 일부 약점이 있음 |
| 3 | 입장과 이유는 있으나 설명의 발전이 제한됨 |
| 2 | 입장은 있으나 뒷받침이 부족하거나 전달되지 않음 |
| 1 | 요구한 입장을 제대로 표현하지 못함 |
| 0 | 유효한 시험 응답으로 볼 내용이 없음 |

오픽형·뉴스형 확장에는 `adapted=true`를 표시한다. 위 표의 활용만으로 공식 시험과 동일한 난도·판정 정확도를 갖추었다고 주장하지 않는다.

### Speakday가 추가한 운영 규칙

1. **기술 실패는 점수와 분리:** 손상·무음·마이크 문제·심한 잡음·도구 실패는 재녹음 또는 평가 보류로 처리한다. 공식 시험의 무응답 처리와 동일하지 않은 학습 서비스 정책이다.
2. **텍스트만으로 문항 점수를 확정하지 않음:** 소리를 평가할 수 없으면 `score=null`, `status=partial`로 반환하고 내용·표현 피드백만 제공한다.
3. **질문의 요구사항을 먼저 정함:** 답변을 읽은 뒤 요구한 적 없는 반론·사례·어려운 문법을 추가하지 않는다.
4. **응답형에서 핵심 요구사항 누락 시 3점 제외:** 이는 이 서비스의 일관성 규칙이다. 한 문장으로 여러 요구를 해결해도 각각 인정한다.
5. **의견형은 필수 요소 개수만 세지 않음:** 입장·뒷받침·전체 전달을 함께 판단한다. 별도로 요구한 우려 대응이 빠지면 확장 과제 미완료를 표시하고 최고점은 주지 않는다. 이 상한은 서비스의 추가 규칙이다.
6. **정확한 짧은 답변 인정:** 필요한 정보를 모두 전달했다면 길이 때문에 감점하지 않는다. 반대로 긴 반복은 높은 점수의 근거가 아니다.
7. **내용과 전달의 근거 분리:** 발음은 실제 음성, 문법은 원음과 대조한 발화, 관련성은 질문과 대조한 내용으로 설명한다.
8. **편향 방지:** 의견의 찬반, 특정 억양, 직업·성별 등으로 점수를 올리거나 낮추지 않는다. 발음은 알아듣는 데 미친 영향으로 설명한다.
9. **근거 없는 정밀도 금지:** 공식 0~200, 오픽 등급, 임의의 소수점 점수·합격 확률을 생성하지 않는다.

## 5. 세부 피드백 형식

아래 영역에는 별도 숫자를 부여하지 않는다. `강점 / 개선 필요 / 관찰 부족 / 적용 안 함` 중 하나와 근거를 남긴다. 유창성은 전달의 보조 관찰이며 별도 가중치 점수가 아니다.

| 영역 | 확인할 증거 |
|---|---|
| 발음 | 원음에서 이해하기 어려웠던 단어·구간과 그 영향 |
| 억양·강세·말의 흐름 | 의미 단위의 끊김, 강조, 반복·중단이 이해에 미친 영향 |
| 문법 | 실제 말한 구조, 오류가 시간·주체·관계에 미친 영향 |
| 어휘 | 과제에 맞는 단어와 풀어 설명하기의 효과 |
| 내용 연결 | 사건 순서·원인·비교·주장과 이유의 관계 |
| 관련성·완성도 | 미리 정한 요구사항의 충족·부분 충족·누락 |
| 정보 정확성 | 제공 자료가 있는 문제에 한해 자료와의 일치. 개인 경험 진위는 검사하지 않음 |

뉴스형은 사용자의 견해에 정답을 정하지 않는다. 기사 내용과 다른 사실을 말했으면 자료 이해 문제와 영어 표현 문제를 구분한다. 확인되지 않은 기사 내용을 채점기가 상상해서 보충하지 않는다.

## 6. 기존 18개 창작 답변 재검토

질문·답변 원문은 [v01의 3장](../speakday-scoring-rubric-2026-10-02-v01.md)에 보존한다. 아래 ID로 식별한다. v01의 T/D 점수·ILR 적용·실행 지침은 읽어 적용하지 않는다. 구현용 입력에는 해당 질문·답변 텍스트만 분리해야 한다.

**아래는 명확한 음성으로 발화했다는 가정 아래의 개발용 후보 범위이며 최종 점수가 아니다. 모든 사례의 실제 `score`는 녹음이 없어 null이다.** 표의 값은 전문가 검증을 거치지 않았고, 실제 음성·문법·어휘 판단에 따라 달라질 수 있다.

| ID | 내용상 후보 | 판정 이유와 보완점 |
|---|---|---|
| Q1-L | 1/3 | 공원을 좋아한다는 말만 반복. 특징·활동·이유가 없음 |
| Q1-M | 2/3 | 장소 특징과 방문은 있지만 좋아하는 이유가 빠짐 |
| Q1-H | 3/3 후보 | 장소·활동·이유가 연결됨. 실제 음성 전달 확인 필요 |
| Q2-L | 1/3 | 여행 취향만 말하고 특정 사건을 서술하지 않음 |
| Q2-M | 2/3 | 사건·대응을 전달하지만 결과가 없음 |
| Q2-H | 3/3 후보 | 사건·변화·대응·결과가 연결됨. 경험 서술 확장 과제 |
| Q3-L | 1/3 | 주말의 중요성만 말하고 비교하지 않음 |
| Q3-M | 2/3 | 과거와 현재는 있으나 변화 이유가 없음 |
| Q3-H | 3/3 후보 | 두 시점과 변화 계기가 연결됨. 비교 확장 과제 |
| Q4-L | 1/3 | 관심만 표현하고 정보를 묻지 않음 |
| Q4-M | 2/3 | 일정·비용은 묻지만 장비는 묻지 않음 |
| Q4-H | 3/3 후보 | 요청한 정보를 모두 질문함. 짧다는 이유로 감점하지 않음 |
| Q5-L | 1/3 | 불만만 있고 상대가 해결할 정보가 없음 |
| Q5-M | 2/3 | 문제·대안은 있으나 사용 가능 여부 확인이 없음 |
| Q5-H | 3/3 후보 | 문제·대안·확인을 모두 전달함. 역할극 확장 과제 |
| Q6-L | 1/5 | 책의 유용성만 말하고 제안에 대한 입장이 없음 |
| Q6-M | 3~4/5 후보 | 입장·이유·예시는 있음. 요청된 비용 우려 대응이 없어 최고점 제외. 전개와 음성 증거로 3·4 경계 검토 |
| Q6-H | 4~5/5 후보 | 입장·사례·우려 대응이 연결됨. 최고점은 음성 전달과 언어 사용까지 검토 후 판단 |

텍스트 정답을 공급한 뒤 그 텍스트의 예상 범위를 재현하는 것은 개발 점검이다. 실제 성적 예측이나 음성 채점 정확성 검증으로 보고하지 않는다.

## 7. 경계 사례 재정의

- Q2-M에 구체적인 도착 결과를 추가하면 응답 완성도는 개선된다. 문항 점수 3점 확정은 원음 평가 후에만 가능하다.
- Q2-M에 모호한 결과만 추가하면 내용이 충분해졌는지 별도로 판단한다. 단어 개수만으로 승급하지 않는다.
- Q4-H에서 장비 질문을 삭제하면 응답형 3점 후보에서 제외한다.
- Q5에서 “Could I use the small room, and could you confirm it is available for thirty minutes?”는 대안과 확인을 모두 수행할 수 있다. 문장 수가 적다고 누락으로 판정하지 않는다.
- Q6-M에 비용을 다루는 문장이 추가돼도 상관없는 내용을 붙였거나 근거가 연결되지 않으면 최고점 후보로 자동 변경하지 않는다.
- Q6의 찬성을 타당하게 전개한 반대 의견으로 바꿔도 동일 기준을 사용한다.
- 파일 손상은 기술 오류, 받아쓰기만 있는 입력은 부분 평가, 유효한 원음에서 영어로 완전히 무관한 말을 한 경우는 0점 후보로 구분한다.

## 8. 일관성 시험 v02

이전 0~4 항목별 수치 목표를 그대로 가져오지 않는다. 다음은 새로운 **개발용 목표**다.

1. 전문가가 평가한 별도 음성 자료를 마련하고, 응답형과 의견형을 나누어 비교한다.
2. 같은 음성을 결과 재사용 없이 5회 평가한다. 각 유형에서 95% 이상의 사례가 최고·최저 점수 차이 1점 이내인지 측정한다.
3. 전문가와의 완전 일치율·1점 이내 일치율·평균 절대 차이·높거나 낮게 치우치는 방향을 유형별로 보고한다. 초기 제안은 1점 이내 90% 이상이지만, 이것만으로 출시 품질이 충분하다고 판단하지 않는다.
4. 독립 평가 A·B의 점수가 다르면 모두 근거 검토 대상이다. 최종 판정을 정당화하지 못하면 보류한다. 임의 평균이나 높은 점수 선택은 금지한다.
5. 받아쓰기 인용·근거 시각이 실제 음성과 일치하는지 검사한다. 존재하지 않는 근거는 0건을 목표로 한다.
6. 오류·보류 비율을 함께 공개한다. 어려운 답변을 모두 보류해 일치율만 높이는 방식은 실패다.
7. 모델·채점표·음성 도구·설정이 바뀌면 동일 자료로 재시험한다.

## 9. 남은 작업

이 문서는 기준 개정을 완료한 것이며 실제 채점 기능은 아직 없다. 다음은 Gemini 설정 확인과 최소 기능 구현이다. 녹음 한 개를 입력해 문항 점수·근거 구간·개선점이 나오는지 확인하고, 이어 반복 평가를 수행한다. 공식 설문 확인·질문 생성 스킬·뉴스 연결·연속 학습 일수는 이후 구현 범위로 유지한다.

- [ETS 자료 이용 정책](https://www.ets.org/legal/permissions/licensing.html): 이전 조사에서 확인한 복제 이용 조건. 개인용이라는 사실만으로 외부 AI 입력·재배포의 포괄 허가를 받았다고 표시하지 않음.
- [Gemini 검토 기록](../speakday-sources-and-gemini-2026-10-02-v01.md): 음성 지원·무료 한도·데이터 취급. 이 문서 중 ILR 중심 적용 결정은 v02로 대체됨.
