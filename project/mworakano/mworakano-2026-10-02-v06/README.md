# 뭐라카노 · 모바일 준비 버전 v06

오픽 향상을 위한 개인 말하기 연습 앱입니다. Gemini가 실제 음성을 듣고 토익스피킹 구조를 응용한 학습용 피드백을 제공합니다. 공식 성적을 산출하지 않습니다.

## PC에서 실행

Node.js 24 이상이 필요합니다. 이 폴더에서 터미널을 열고 `npm start`를 실행한 뒤 http://127.0.0.1:8798/ 에 접속하세요. 외부 패키지 설치는 없습니다. 종료는 터미널에서 Ctrl+C입니다.

키가 없어도 준비된 질문·녹음·직접 기록을 사용할 수 있습니다. 연결 화면에서 Gemini 키를 입력하면 이번 서버 실행 동안 메모리에서만 사용합니다. 지속 설정은 `.env.example`를 참고해 비공개 `.env`에 저장합니다. 기존 파일은 보존하세요. 키를 GitHub나 채팅에 올리지 않습니다.

## 휴대폰에서 사용

[모바일 접속 안내](MOBILE.md)에 따라 개인 HTTPS 주소와 비밀번호를 설정합니다. 홈 화면 아이콘·모바일 입력창·앱 전환 시 녹음 종료를 준비했습니다. 실제 휴대폰 접속 주소는 아직 생성하지 않았습니다. PC의 localhost 주소로 휴대폰에서 연결할 수는 없습니다. GitHub Pages만으로는 Node 서버와 키가 필요한 채점을 실행할 수 없습니다.

## 기능

관심사 설문, 5가지 질문 유형, Gemini 질문 생성, 최대 180초·8MB 녹음, 독립 평가 2회와 필요 시 재검토 1회, 음성 근거와 개선점, CNN·WSJ 제목·링크 기반 의견 연습, 서울 날짜의 학습일수와 기록을 제공합니다.

일반 0~3, 의견 0~5는 학습용 점수입니다. 최신 국내 OPIc 설문과의 완전한 일치와 실제 채점 정확도는 검증 전입니다. 뉴스 전문과 항상 최신인 기사 수집은 제공하지 않습니다.

## 데이터와 검증

기록은 기기·주소별 브라우저에 저장합니다. 최근 답변 200개와 전체 학습일을 보관하고 JSON 백업을 제공합니다. 원본 녹음은 영구 저장하지 않으므로 새로고침 전에 내려받아 주세요. 백업 복원·기기 동기화·오프라인 기능은 없습니다.

`npm test`로 주요 규칙을 확인합니다. 자동 검사에는 인위적인 AI 응답을 사용하므로 실제 평가 품질의 증거는 아닙니다. 실제 iPhone/Android 녹음·홈 화면 설치·Docker 실행·HTTPS 운영·Gemini 요청은 후속 확인이 필요합니다.
