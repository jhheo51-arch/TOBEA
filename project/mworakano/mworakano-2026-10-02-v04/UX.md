# 뭐라카노 v04 화면 기준

사용자의 M. 말풍선·파란색 선호를 유지하고 ui-ux-pro-max의 구체적인 UX 지침을 적용한다. 새 테마나 외부 UI 라이브러리는 추가하지 않는다.

- Progress Indicators: 질문→말하기→피드백의 현재 단계를 실제 상태로 표시한다. 평가 진행률을 임의로 만들지 않는다.
- Disabled States: 녹음·동의·연결 중 무엇이 필요한지 채점 버튼 가까이 설명한다.
- Back Button: 메뉴 이동 기록을 남기고 뒤로가기로 이전 화면을 복원한다. 진행 중인 녹음은 이동으로 잃지 않게 한다.
- Sticky Navigation / focus-not-obscured: 모바일 4개 메뉴를 하단에 배치하고 본문·초점에 여유 공간을 둔다.
- touch-target-size / Mobile Keyboards: 버튼 44px 이상, 입력창 16px, 키보드와 손가락으로 모두 접근 가능하게 한다.
- reduced-motion: 움직임 줄이기 설정에서는 스크롤 이동과 장식 동작을 줄인다.

장식보다 다음 행동을 우선한다. 질문 아래 말하기 이동 버튼, 녹음 상태, 기록이 없을 때의 시작 버튼을 제공한다. 실제 AI 점수나 학습일을 꾸며 넣지 않는다. 키 연결을 먼저 할 수 있게 설정 화면의 모바일 설명은 펼침 영역으로 옮긴다.

검증은 좁은 화면의 가로 넘침·하단 메뉴와 본문 겹침, 질문에서 녹음 이동, 비활성 버튼 설명, 메뉴와 뒤로가기, 빈 기록 시작, 콘솔 오류를 확인한다. 실제 마이크·Gemini 채점·실제 휴대폰 설치는 별도 검증이다.
