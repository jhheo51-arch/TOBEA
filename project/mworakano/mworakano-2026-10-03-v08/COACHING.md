# v08 현재 동작 — 이전 점수 관련 문서보다 우선

## 점수 없는 일일 코칭
질문 선택 → 녹음 → Gemini 전송 동의 → 코칭 → 같은 질문 재도전 → 요구사항 판정과 전후 답변 비교.
숫자 점수나 등급을 만들지 않습니다. 잘한 점과 최우선 개선 한 가지, 받아쓰기·개선 예문·음성 근거를 제공합니다. 원음 근거 부족은 보류합니다. 두 독립 코칭의 요구사항·영역 판정이 다르면 재검토합니다. 오픽 모의시험과 비공식 예상 등급은 미구현입니다.

## 재도전
결과의 같은 질문에 다시 말하기 버튼을 누르면 이전 결과를 고정합니다. 새 녹음의 코칭 결과와 요구사항 판정을 비교합니다. 변화 없음·충족 범위 축소·비교 보류도 표시합니다. 공식 성적 향상의 증명은 아닙니다. 질문을 바꾸면 비교를 초기화합니다. 기록의 재도전 항목에서 이전·이번 받아쓰기를 볼 수 있습니다.

## 실행과 비공개 Sites
- Node 24 이상, npm start, 로컬 http://127.0.0.1:8800/#today
- npm test: 실제 AI를 호출하지 않는 검사. npm run build: 단일 Workers ESM 출력.
- 로컬은 server.mjs, Sites는 worker.js. 공유 평가는 evaluation.js와 public/core.js.
- Sites의 소유자 비공개 접근을 유지하며 인증된 사용자 헤더가 없으면 거절합니다.
- SESSION_SECRET은 Sites의 비밀 설정입니다. 소스와 배포파일에 넣지 않습니다.
- 사이트 설정에서 입력한 Gemini 키는 사용자에 묶인 AES-GCM 암호화 보안 쿠키로 최대 12시간 유지합니다. HttpOnly로 브라우저 스크립트에서 읽을 수 없고 서버에서만 복호화합니다. 만료 후 다시 연결합니다.
- 기본 모델은 gemini-3.8-flash. 실제 호출 권한·한도는 사용자의 Gemini 프로젝트에 따라 달라집니다.
- 질문 토큰도 사용자·만료기간에 묶어 변조를 검증합니다. 음성은 동의 후 Gemini에 보내며 앱 서버에 영구 저장하지 않습니다.

## 기록과 이전
연습 기록은 기존과 같이 기기·브라우저에 저장합니다. PC 로컬 주소와 배포 주소의 기록은 별개입니다. 기록 탭의 백업으로 파일을 보관할 수 있지만 가져오기·기기 동기화는 아직 없습니다. 키는 학습 기록에 저장하지 않습니다.

## 이용권 종료
2026-10-03 공식 Sites 안내는 지원 유료 플랜과 사용 한도를 안내하지만 구독 종료 후 기존 비공개 사이트 유지 여부는 명시하지 않습니다. 지속 이용을 보장하지 않습니다. https://learn.chatgpt.com/docs/sites
소스는 로컬 Node와 표준 Worker 형식으로 보존해 다른 호스팅으로 이전할 수 있습니다. Gemini API 이용 조건은 별도입니다.

## Claude 개발 인계
이 문서가 이전 README·PRD·UX·채점 명세의 숫자 평가 설명보다 우선합니다. status는 coached/deferred, score/grade/scale_max 결과는 거부합니다. 개선점은 최대 1개. public/result-view.js는 실제·예시 공통 화면, compareAttempts는 시험등급 대신 요구사항 판정 변화를 표시합니다. 예시가 학습 기록에 들어가지 않도록 유지합니다. worker.test.mjs는 배포 Worker의 인증·쿠키·질문 변조·코칭 흐름을 실제 AI 호출 없이 검증합니다. 배포 시 기존 .openai/hosting.json의 project_id를 유지합니다.

다음 과제: 실제 녹음으로 코칭 정확도 확인, 기록 가져오기와 기기 동기화, 여러 유형의 답변을 묶은 모의시험·예상 등급 검증.
