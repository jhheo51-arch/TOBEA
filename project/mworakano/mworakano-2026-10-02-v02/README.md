# 뭐라카노 · 매일 영어 한마디

오픽 대비 개인 말하기 연습 앱입니다. Gemini가 실제 음성을 듣고 토익스피킹 기준을 응용한 학습용 피드백을 제공합니다. 공식 성적을 산출하지 않습니다.

## 시작

Node.js 24 이상이 필요합니다. 이 폴더에서 터미널을 열고 실행합니다. 별도 패키지 설치는 없습니다.

```powershell
npm start
```

브라우저 주소창에 **http://127.0.0.1:8794/** 를 입력합니다. 처음에는 관심사 설문이 보입니다. 저장 후 질문과 녹음 화면이 나타나면 시작 준비가 된 것입니다. 터미널에서 실행했다면 종료는 Ctrl+C입니다.

키가 없어도 준비된 질문·녹음·직접 연습 기록을 사용할 수 있습니다. **Gemini 연결하기** 화면에 본인의 키를 입력하면 실행 중 서버 메모리에서만 사용합니다. 키를 채팅에 붙여 넣지 마세요. 기존 프로젝트 `.env`는 수정하지 않았습니다.

개발자가 지속 설정을 지원할 때에는 이 버전 폴더에 `.env.example`를 참고해 `.env`를 새로 만들고 `GEMINI_API_KEY`, `GEMINI_MODEL`을 설정할 수 있습니다. 기존 파일은 먼저 존재 여부를 확인해 보존해야 합니다. 환경변수는 프로그램 설정값이며 그 자체로 비밀을 암호화하는 기능은 아닙니다. 버전 `.env`는 부모 `.env`보다 우선하고 운영체제 환경변수는 둘보다 우선합니다. `.env`는 공유하지 않습니다.

## 화면에서 확인하기

1. **나의 관심사**를 저장하고 질문이 선택 주제에 맞는지 봅니다.
2. **녹음 시작**으로 5초 이상 말하고 **녹음 마치기**를 누른 뒤 재생합니다. 마이크 권한은 사용자가 브라우저에서 허용합니다.
3. **오늘 연습 기록하기**를 누르면 총 연습일이 늘어납니다. 같은 날짜에는 중복 증가하지 않습니다.
4. Gemini를 연결한 경우 전송 동의에 체크하고 **내 답변 채점하기**를 누릅니다. 2~3회 AI 요청이 발생합니다.

뉴스는 원문 링크로 읽고 본인의 요약·의견을 연습합니다. 공개 목록이 오래되거나 연결되지 않으면 직접 CNN·WSJ 제목과 주소를 입력할 수 있습니다.

## 데이터 보관

학습 기록은 해당 브라우저에만 저장됩니다. 최근 답변 200개와 전체 학습 날짜를 보관합니다. **기록 백업**으로 JSON 파일을 받을 수 있으나 이 버전에는 복원 화면이 없습니다. 녹음 원본은 저장하지 않으니 필요한 녹음은 **녹음 내려받기**로 보관하세요. 새로고침하면 현재 녹음은 사라집니다.

## 검증 상태와 제한

```powershell
npm test
```

프로그램 자동 검사 통과. 서버 시작 확인. Gemini 키 미연결로 실제 음성 채점은 미검증입니다. 브라우저 자동 검사도 로컬 주소가 브라우저 환경에서 차단되어 완료하지 못했습니다. 마이크·파일·화면·구간 재생을 사용자 브라우저에서 확인해야 합니다.

국내 OPIc 최신 설문과 완전히 같은 선택지는 아직 확보하지 못했습니다. 뉴스 전문 표시·항상 최신인 뉴스 수집은 제공하지 않습니다. 음성 근거의 실제 정확도와 점수 신뢰도는 실제 녹음으로 보정해야 합니다. 무료 Gemini도 사용 한도가 있습니다.
