# 휴대폰에서 뭐라카노 사용하기

이 버전은 모바일 화면·홈 화면 아이콘·HTTPS 앞단 연결·개인 비밀번호 보호를 준비했습니다. **아직 인터넷이나 개인 네트워크에 배포하지 않았으며 실제 iPhone/Android에서 녹음·설치를 검증하지 않았습니다.** GitHub에 코드가 올라가는 것과 휴대폰 접속 주소가 생기는 것은 다릅니다.

## 권장: 개인 네트워크의 HTTPS 주소

혼자 사용할 때에는 PC에서 서버를 실행하고 휴대폰과 PC를 같은 개인 네트워크 서비스에 연결한 뒤, HTTPS 연결을 제공하는 Tailscale Serve 같은 기능으로 연결할 수 있습니다. 서비스 가입·설치·네트워크 연결은 사용자가 선택하는 별도 단계입니다. 이를 자동 설치하거나 공개 터널을 열지는 않았습니다.

운영 담당자는 다음 조건을 만족하도록 설정합니다.

1. `PUBLIC_ORIGIN`에 실제 HTTPS 주소의 출처 부분만 설정합니다. 예: `https://my-pc.example.ts.net`. 이 예제 주소는 사용할 수 있는 실제 주소가 아닙니다.
2. `APP_PASSWORD`에 무작위로 만든 16자 이상의 개인 비밀번호를 설정합니다. 앱 로그인 사용자명은 `mworakano`입니다. 비밀번호와 Gemini 키를 GitHub 또는 채팅에 올리지 않습니다.
3. 로컬 연결은 `HOST=127.0.0.1`, `PORT=8799`를 유지합니다. HTTPS 앞단은 해당 포트로 연결하고 원래 Host·Origin·Authorization을 보존해야 합니다. Host를 localhost로 바꾸는 프록시에서는 원래 HTTPS Host를 전달하도록 설정합니다.
4. `npm start` 후 실제 HTTPS 주소에서 로그인합니다. 공개 공유 기능은 사용하지 않고 개인 네트워크 접근을 권장합니다. PC를 끄거나 절전하면 연결되지 않습니다.
5. 휴대폰에서 HTTPS 주소를 열고 마이크 권한을 허용합니다. 브라우저의 공유/메뉴에서 ‘홈 화면에 추가’ 또는 앱 설치 기능을 사용합니다. 메뉴 이름과 설치 가능성은 OS·브라우저 버전에 따라 다릅니다.

HTTP의 사설 IP 주소를 휴대폰에서 여는 것만으로는 마이크가 동작하지 않습니다. 휴대폰의 `127.0.0.1`은 휴대폰 자신을 가리키며 PC 주소가 아닙니다.

## 컨테이너 실행을 선택하는 경우

Dockerfile은 앱을 같은 환경에서 실행하는 묶음입니다. Docker가 준비된 운영 환경에서 이 폴더를 기준으로 빌드합니다.

```sh
docker build -t mworakano .
docker run --rm --env-file .env -e HOST=0.0.0.0 -e PORT=8799 -p 127.0.0.1:8799:8799 mworakano
```

이 경우에도 `.env`의 HTTPS `PUBLIC_ORIGIN`과 `APP_PASSWORD`가 반드시 필요합니다. 외부 수신만 열고 비밀번호를 생략하면 시작을 거부합니다. 호스트 PC의 HTTPS 앞단만 이 컨테이너에 연결합니다. 이미지에 `.env`는 포함하지 않습니다. Docker 실행은 이번 환경에서 검증하지 않았습니다.

인터넷 공개 호스팅을 선택한다면 인증·TLS·프록시 시간 제한·요금·접근 제한을 먼저 확인하세요. AI 요청은 여러 번 순차 진행하므로 앞단의 요청 제한 시간도 확인해야 합니다. 기본 비밀번호 방식은 개인용으로만 설계했으며 여러 사용자 계정 서비스가 아닙니다.

## 모바일 검증 순서

- 첫 방문 설문 → 질문 선택 → 10초 녹음 → 재생 → 연습 기록.
- 화면 잠금/다른 앱 이동 시 녹음 종료 안내와 재생 가능 여부 확인.
- iOS의 MP4 녹음과 Android의 WebM 녹음을 각각 실제 Gemini로 채점.
- 홈 화면 아이콘·다시 실행·로그인 유지 상태를 각 기기에서 확인.
- 잘못된 비밀번호로 API와 설정 화면에 접근할 수 없는지 확인.

네트워크가 연결되어 있어야 질문 요청과 채점이 가능합니다. 오프라인 기능은 없습니다. 브라우저·주소·기기별 학습 기록은 분리됩니다. 원본 녹음은 새로고침 전에 내려받고, 장기 기록은 백업하세요. PC 기록을 모바일로 자동 동기화하는 기능은 아직 없습니다.
