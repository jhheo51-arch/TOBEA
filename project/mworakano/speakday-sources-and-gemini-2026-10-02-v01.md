# Speakday · 공식 채점 자료 조사와 Gemini 연결 검토

확인일: 2026-10-02. 조사·설계 기록이며 외부 AI 호출과 키 변경은 수행하지 않았다.

## 1. 공식 자료는 있는가?

**있다. 다만 열람 가능 여부와 서비스에 복제·입력할 수 있는지는 별개다.**

| 후보 | 확인한 자료 | 이번 적용 |
|---|---|---|
| TOEIC Speaking | ETS 응시자 안내서에 문제 유형별 채점표. 17·19·20·22·24쪽 일대에 읽기·설명·응답·의견 유형의 기준 제공 | 공식 자료 링크와 비교 참고. 원문 평가표·기출문제 복제 제외 |
| TOEIC 기준 답변 | ETS 2010 연구 보고서는 채점자 훈련에 점수별 실제 기준 답변과 판정 이유를 사용하는 절차를 설명 | 기준 사례·독립 평가·불일치 검토라는 운영 원리 참고. 실제 훈련용 답변 묶음을 확보한 것은 아님 |
| OPIc | LTI 안내서와 ACTFL 소개에 평가·시험 설명 및 샘플 안내 | 공인 판정이 붙고 자유롭게 재사용할 수 있는 전체 음성 묶음은 이번 조사에서 확보하지 못함 |
| ILR | 기존 조사에서 특정 HL7 판본의 등급 설명과 공개 이용 고지를 확인 | 합의한 종합 평가 참고 자료로 유지. 실제 답변 녹음 자료와는 구분 |
| 유사 공개 교육 자료 | INTEF의 Voices in the Media 평가표, CC BY-SA 4.0 표시 | 출처 표시·동일 조건 공유가 필요한 자료. 협동 활동 등을 포함한 수업 평가여서 오픽형 개인 말하기 채점에 그대로 적용하지 않음 |

ETS의 라이선스 정책은 자료 복제 신청과 허가 조건을 안내하고 있으며 답변·음성도 라이선스 대상에 포함한다. 현재 이 프로젝트가 해당 허가를 확보한 것은 아니다. ‘공식 기준이 없다’는 결론이 아니라 ‘바로 복제해 쓸 수 있는 완성 묶음은 확보하지 못했다’는 결론이다.

따라서 사용자 요청의 창작 허용에 따라 [세부 채점표와 18개 기준 답변](speakday-scoring-rubric-2026-10-02-v01.md)을 자체 작성했다. 공식 답변을 번역하거나 이름만 바꿔 만든 자료가 아니다. 자체 점수는 전문가 검증 전 개발용 예상값이다.

## 2. Gemini 키로 가능한가?

가능하다. Gemini API는 녹음 입력, 음성 이해, 받아쓰기와 시간 구간을 포함한 출력을 지원한다. 따라서 질문 생성과 답변 평가를 Gemini에 연결하는 구조를 만들 수 있다. 하지만 음성 입력을 지원한다는 사실이 발음 채점 정확도를 보증하지는 않는다. 타임스탬프와 판단 근거를 실제 녹음과 대조해야 한다.

API는 프로그램이 AI를 호출하는 연결 기능이며, 키는 그 연결에 사용하는 비밀 인증값이다. 기존 OpenAI 키를 Gemini 요청에 그대로 사용할 수는 없다. 공급자에 맞는 호출 코드와 Gemini 키가 필요하다. 키 내용은 채팅에 붙여 넣지 않는다.

## 3. 무료와 무제한의 차이

- Gemini API에는 일부 모델의 무료 사용 구간이 있지만 무제한은 아니다.
- 모델과 프로젝트 요금제에 따라 분당 요청 횟수, 분당 입력 처리량, 일일 요청 횟수 등이 제한된다. 하나라도 초과하면 제한 오류가 발생할 수 있다.
- 한도는 API 키별이 아니라 프로젝트별이다. 같은 프로젝트에서 키를 더 만든다고 한도가 늘지 않는다.
- 실제 한도는 해당 계정의 Google AI Studio에서 확인해야 한다. 현재 사용자 계정의 한도는 확인하지 않았다.
- 가격표에는 무료 지원이 없는 모델·기능도 있다. 유료 프로젝트에 연결하면 선택한 모델·기능의 요금이 적용될 수 있다. 웹사이트에서 무료로 사용해 봤다는 사실만으로 API 비용을 판단하지 않는다.
- 채점 A·B는 최소 2회 요청이다. 질문 생성·음성 처리·검토를 별도 호출하면 횟수가 더 늘어난다. 무료 한도 내 학습 가능 횟수를 지금 확정할 수 없다.

제안: 공급자 교체가 가능한 구조를 유지하면서 Gemini를 연결 후보로 삼는다. 한도 초과 시 재시도 횟수를 제한하고 답변을 보존해 나중에 채점한다. 오류를 정상 점수로 만들거나 사용자 승인 없이 다른 유료 공급자로 전환하지 않는다.

## 4. 녹음 자료를 보내기 전 확인할 사항

Google의 무료 서비스 약관은 입력·출력이 제품 개선에 쓰일 수 있고 사람이 검토할 수 있다고 설명한다. 민감·기밀·개인정보를 제출하지 말라고 안내한다. 지역·결제 설정에 따른 예외도 있으므로 실제 프로젝트 조건을 확인해야 한다.

오픽 연습에는 개인 경험과 음성이 포함되므로 서비스 화면에 전송 대상과 데이터 취급을 설명한다. 초기 기능 시험은 가상 내용으로 하고, 실제 녹음 전송은 선택한 서비스 조건과 사용자 동의를 확인한 뒤 수행한다. 결제된 서비스의 취급 조건을 무료 서비스와 동일하다고 단정하지 않는다.

## 5. 현재 상태

- 공식 채점표와 기준 답변 운영 방식 조사: 완료.
- 자체 점수별 조건과 텍스트 기준 답변: v01 작성.
- 실제 기준 음성·전문가 점수: 미확보.
- Gemini 사용자 키·계정 한도 확인: 미수행.
- .env 변경·키 생성·AI 호출·모델 전환: 미수행.
