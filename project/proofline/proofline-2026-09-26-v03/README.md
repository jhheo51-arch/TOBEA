# PROOFLINE v03 — 가상 사례 시연

`index.html`을 브라우저에서 열고 **가상 사례 불러와 저장하기**를 누르세요.

가상 인물 박다은의 고민과 경험이 왼쪽 양식에 들어갑니다. 오른쪽에는 강점 가설, 중요한 조건, 첫 방향, 자기소개 초안, 첫 행동이 한 장으로 표시됩니다. 아래 **이 브라우저의 기록**에는 해당 사례가 저장되어 다시 열 수 있습니다.

이야기와 성과 수치는 모두 시연을 위해 만든 허구입니다. 사회·산업 흐름은 자료를 넣지 않았으므로 **조사 전**으로 표시합니다. 이 화면은 입력 내용을 정리하는 시제품이며, AI가 사실을 조사하거나 진로를 판정하지 않습니다.

기록은 현재 브라우저의 로컬 저장소에 최대 20개까지 남습니다. 계정과 외부 서버는 없습니다. 브라우저의 사이트 데이터가 삭제되면 기록도 사라질 수 있습니다.

코드 문법은 `node --check script.js`로 확인할 수 있습니다. 브라우저 주소에 `?selftest=1`을 붙이면 개발자 콘솔에서 기본 결과 구성 검사가 실행됩니다.
