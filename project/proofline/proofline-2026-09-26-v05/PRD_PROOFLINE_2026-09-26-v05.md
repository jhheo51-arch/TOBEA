# PROOFLINE PRD v05 — 구현 확인

작성일: 2026-09-26 · [서비스 방향과 창업자 배경이 담긴 PRD v04](../proofline-2026-09-26-v02/PRD_PROOFLINE_2026-09-26-v04.md)를 이어받습니다.

## 방향

초기의 핵심은 **실제 경험을 근거로 자기 가치를 설명하고, 필요한 사람에게 첫 도움을 제안하는 것**입니다. 이후 참가자의 설명에 따라 대상은 소상공인이나 초기 창업자로 제한하지 않습니다. 진로·활동 방향이 막막한 개인도 포함합니다. 그러나 진로 조언만 하는 서비스로 줄이지 않고, **강점 → 방향 → 자기소개 → 첫 활동 또는 서비스 → 알릴 이야기 → 실제 반응에 따른 수정**을 한 흐름으로 제공합니다.

운영자의 역할은 이야기를 듣고 근거를 확인하며 선택지를 제안하는 것입니다. 웹은 그 대화와 결과를 보관하는 작업 도구입니다. 한 장 카드가 끝이 아니라, 실제로 해보고 다시 고칠 때까지 한 사람의 기록이 이어집니다.

## 이 버전의 완료 범위

| 요구 | v05에서 확인할 동작 |
| --- | --- |
| 경로를 고르지 않는 상담 기록 | 한 양식에 이야기·경험·중요 조건·도울 사람을 적음 |
| 근거가 있는 강점 | 강점과 장면 근거를 쌍으로 기록하며 두 번째 강점에 근거가 없으면 저장 전에 안내 |
| 출처 있는 사회·산업 흐름 | 자료 이름·웹 주소·확인 날짜가 있어야 카드에 표시, 부족하면 ‘조사 전’ |
| 방향 1~2개와 이유 | 두 선택지와 각각의 이유, 본인이 고른 방향을 표시 |
| 브랜딩과 첫 제안 | 자기소개, 작은 활동·서비스, 처음 알릴 이야기, 첫 행동, 확인 질문을 같은 카드에 표시 |
| 반응 후 수정 | 실제 행동·상대 반응·수정·다음 행동을 같은 사람의 새 카드 버전으로 저장 |
| 수정·저장·공유 | 기존 기록을 열어 수정해 새 버전 저장, 현재 카드 복사·텍스트 저장 |
| 가상 사례 시연 | 허구의 인물 박다은의 1차 카드와 2차 수정 카드를 한 번에 불러와 비교 |

## 한계와 다음 검증

이 버전은 입력을 구조화하는 로컬 시제품입니다. 실제 상담, 경험 증빙, 자료 내용 확인, 진로 적합성 판단, 다른 사람의 반응 수집은 사람이 해야 합니다. 웹 주소의 형식은 검사하지만 출처의 진위를 자동 검증하지 않습니다. 외부 AI·계정·예약·결제는 연결하지 않았습니다.

우선 가격을 정하지 않고 5명의 실제 사용자가 질문을 이해하는지, 결과가 자기 말처럼 느껴지는지, 첫 행동을 실행했는지 관찰합니다. 유료화와 대행·제작 연계는 그 뒤에 검토합니다.
