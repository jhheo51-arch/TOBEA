# PROOFLINE v05 — 가상 사례로 보는 전체 흐름

브라우저에서 `index.html`을 열고 **가상 사례 전체 보기**를 누릅니다. 가상의 박다은 사례가 저장되며, 오른쪽의 **1차 · 첫 카드 / 2차 · 반응 후 수정** 버튼으로 두 결과를 비교할 수 있습니다. 아래 **이 브라우저의 기록**에서 다시 열 수도 있습니다.

## 무엇이 이어지나요?

이야기와 실제 경험 → 근거가 있는 강점 1~2개 → 중요 조건과 관련 자료 → 가능한 방향 1~2개와 이유 → 본인이 고른 방향 → 자기소개·첫 활동·처음 알릴 이야기 → 첫 행동과 확인 질문 → 실제 행동·반응·수정.

왼쪽 입력을 고쳐 **한 장 저장 / 수정**을 누르면 같은 사람의 새 카드 버전이 쌓입니다. **카드 복사** 또는 **텍스트 저장**으로 현재 보고 있는 버전을 꺼낼 수 있습니다. **새 기록 시작**은 이전 기록을 지우지 않습니다. 선택한 기록은 **이 기록 삭제**로 지울 수 있습니다.

예시 사람, 행동, 반응은 모두 허구입니다. 산업 참고 자료만 [한국지능정보사회진흥원 2025년 고령층 디지털 교육 사례](https://www.nia.or.kr/site/nia_kor/ex/bbs/View.do?bcIdx=28573&cbIdx=99938&parentSeq=28573)를 사용했습니다. 이는 안내 방식의 사례이며 가상 인물의 진로 적합성이나 사업 수요의 증거가 아닙니다.

이 앱은 **상담 중 함께 작성한 내용**을 카드로 정리합니다. 경험의 사실 여부를 자동 검증하거나 AI가 진로를 판정하지 않습니다. 자료 이름·주소·확인 날짜가 빠지면 관련 흐름을 **조사 전**으로 표시합니다. 이용자의 기록은 현재 브라우저에만 최대 20명까지 보관됩니다. 사이트 데이터를 지우면 기록도 없어질 수 있습니다. 가격·결제·예약은 추후 결정합니다.

검사: `node --check script.js`, `node check.cjs`.
