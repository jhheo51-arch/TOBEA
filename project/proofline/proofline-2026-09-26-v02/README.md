# PROOFLINE v02

기본 전략은 **유료 진단 → 5일 오퍼 설계 → 필요할 때만 마케팅·디자인·IT 실행 연계**입니다. 교육은 상담에서 반복되는 문제를 확인한 뒤 소규모로 시험합니다. 가격과 기간은 검증 전 가설입니다.

상품·고객·운영 기준과 첫 4주 검증 계획은 [PRD_PROOFLINE_2026-09-26-v02.md](PRD_PROOFLINE_2026-09-26-v02.md)에 있습니다. 입력은 브라우저에만 보관되고 외부 서버로 보내지지 않습니다. 현금 계산은 직접비만 반영하며 순이익이나 미래 매출 예측이 아닙니다.
