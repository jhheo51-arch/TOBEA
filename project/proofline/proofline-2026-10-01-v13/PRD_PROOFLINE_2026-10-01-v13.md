# PROOFLINE PRD v13 — 기록의 최종 결과 요약

작성일: 2026-10-01. v12의 상담·제안·실행·백업 흐름과 원래 시각 디자인을 유지한 채 비공개 Sites의 최종 결과물을 개선합니다. 유료화는 이번 범위에 포함하지 않습니다.

## 이번 개선의 문제와 결과

기존 화면에서는 방향 카드, 제안 문구, 실행 반응이 서로 떨어져 있었습니다. 한 사람의 기록에서 가장 최근 방향과 제안, 실제로 기록된 반응을 모아 **결과 요약**으로 보여줍니다. 가상 박다은 사례를 버튼 하나로 열어 사용자가 자기 기록을 쓰기 전에 결과 형태를 볼 수 있습니다.

## 결과 요약의 구성

1. 선택한 방향과 현재 진행 상태
2. 강점 후보, 직접 한 행동이라는 근거, 당시 실제로 들은 반응
3. 먼저 도울 사람과 그 사람의 상황 가설
4. 작은 제안의 시간·결과물·제외 범위와 바로 쓸 문구
5. 어느 버전의 제안을 실제 알렸는지, 그때 기록한 반응·관심·질문·참여·문의
6. 다음 행동과 아직 확인되지 않은 점

텍스트 복사·저장·인쇄/PDF 저장을 지원합니다. 원본 기록과 제안의 수정 이력은 그대로 보존합니다. 요약은 가장 최근 저장 기록을 읽어 만들며, 사용자가 입력하지 않은 성과를 생성하지 않습니다.

## 완료 기준

- 박다은 사례에는 모든 내용이 창작 시연이라고 명시합니다. 실제 시범 운영 통계에는 포함하지 않습니다.
- 실행 기록이 없는 제안은 실행한 것처럼 표현하지 않습니다. 1차 제안의 반응만 있을 때 2차 제안은 실행 전이라고 표시합니다.
- 숫자를 적지 않았다면 0이 아닌 ‘미확인’으로 표시합니다.
- 본인 기록도 같은 결과 요약에 반영되고, 수정한 뒤에는 화면의 요약이 갱신됩니다.
- 기존 녹색·크림색과 서체를 유지합니다.

## 목적

개인의 경험을 보기 좋은 문장으로만 정리하지 않고, **누가 어떤 상황에서 필요한지 → 어떤 작은 도움을 줄지 → 실제로 알린 뒤 어떤 반응이 있었는지** 한 기록으로 연결합니다. 창작 시연과 본인 체험, 실제 시범 고객을 구분합니다.

## 핵심 흐름

1. **내 이야기로 시작:** 이름/가명, 고민, 직접 한 일, 실제로 들은 반응(선택), 스스로 본 강점, 첫 대상 한 유형과 상황, 작은 활동을 입력합니다. 입력한 말로 방향 카드 초안을 만들며 자동 진단이나 수요 검증으로 표시하지 않습니다.
2. **경험과 해석 분리:** 직접 한 일·실제 들은 반응·강점 가설·대상 상황 가설을 카드에서 구분합니다. 반응이 없으면 0건이라고 쓰지 않고 미확인으로 표시합니다.
3. **작은 서비스 정의:** 도울 사람과 불편, 도움의 변화, 활동, 걸리는 시간, 받는 결과물, 제외 범위, 알릴 채널과 요청 행동을 입력해 첫 제안 문구를 만듭니다.
4. **실제 알린 뒤 기록:** 문구 저장·복사는 실행으로 계산하지 않습니다. 실제 게시·대화 뒤 날짜·장소, 반응, 관심, 추가 질문, 참여, 문의, 직접 들은 거절 이유를 기록합니다. 숫자는 미확인과 0을 구별합니다.
5. **반응을 근거로 수정:** 2차 제안부터 변경 이유를 필수로 적고 이전 버전을 보존합니다. 버전별 실행 횟수와 확인된 반응을 나란히 보여줍니다. 대상·노출 조건이 달라 단순 수치 차이를 개선 효과로 단정하지 않습니다.

## 기존 흐름 유지 기준

- 본인 체험 카드 생성 시 가상 사례를 자동으로 끼워 넣지 않고, 실제 시범 고객 수에도 포함하지 않습니다.
- 상담 후보 등록과 기존 카드·제안·실행 이력은 유지됩니다. 이전 버전에서 저장한 기록은 새 필드가 비어 있어도 열 수 있습니다.
- 결과 카드에는 과거 반응과 대상 상황의 출처 상태가 명시됩니다.
- 새 제안은 시간·결과물·제외 범위가 없으면 저장할 수 없습니다. 수정 이유 없는 2차 제안도 저장되지 않습니다.
- 실제 게시·제안 기록의 미확인 숫자는 0으로 합산하지 않습니다. 미래 날짜의 실행 기록은 저장하지 않습니다.

## v12 추가: 백업·복원

- 사용자는 이 브라우저에 저장된 실제 상담 기록과 상담 후보를 JSON 파일로 내려받을 수 있습니다. 가상 사례는 제외합니다.
- 파일을 선택해 불러오면 기존 기록을 보존하고, 같은 ID는 건너뜁니다. 새 기록이나 후보를 더해 각 20개 보관 한도를 넘으면 가져오지 않습니다.
- 형식이 다르거나 손상된 파일은 거절합니다. 저장에 실패하면 기존 저장값으로 되돌리고 실패를 안내합니다.
- 파일은 사용자의 기기 안에서 읽으며 사이트 서버로 보내지 않습니다. 사용자에게 개인 이야기가 들어간 파일임을 알립니다.

## 이번 단계에서 확인하지 못한 것

실제 고객 모집, 고객의 동의, 게시·대화, 반응, 사업 수요는 프로그램만으로 검증할 수 없습니다. 화면의 개인 체험은 본인 입력을 정리하는 작업이고, 가상 박다은 사례는 허구입니다. 실제 고객 한 명과 끝까지 운영하기 전에는 서비스 성과를 주장하지 않습니다.

## 저장과 공개 범위

사이트는 소유자만 접속할 수 있는 비공개 Sites입니다. 입력 기록은 접속한 브라우저의 저장 공간에 보관되며 다른 기기로 자동 동기화되지 않습니다. 사용자가 내려받은 백업 파일을 다른 브라우저에서 직접 불러올 수 있습니다.
