# PROOFLINE v09 — 첫 고객 모집부터 첫 제안 동행까지

[`index.html`](index.html)을 열면 맨 위에 **첫 고객 모집 준비**가 있습니다. 모집 문구를 복사할 수 있고, 실제로 참여 의사를 밝힌 사람이 생기면 동의를 확인해 상담 후보로 기록합니다. 후보의 **이 후보로 상담 시작**을 누르면 기존 이야기 입력으로 이어집니다. 이후 방향 카드 → 첫 제안 문구 → 고객의 실제 실행·반응 순서로 진행합니다.

가상 박다은 사례는 **가상 사례 보기**를 누르면 모집 답장부터 반응 후 수정까지 4단계로 먼저 보입니다. 아래 **가상 방향 카드와 제안 보기**를 누르면 상세 기록으로 이동합니다. 가상 사례는 실제 후보와 시범 운영 수치에 포함되지 않습니다. [가상 첫 고객 운영 시연](FICTIONAL_FIRST_CUSTOMER_2026-09-28-v01.md)과 [가상 사례 텍스트](fictional-pilot-v09.txt)도 함께 제공합니다.

실제 사람이나 소유한 모집 채널이 아직 없으므로 고객 접촉·상담·게시·반응 확인은 이 버전에서 완료되지 않았습니다. 모집 문구는 복사만 하며 외부 메시지를 보내지 않습니다. 현재는 로컬 파일이라 공개 신청 주소도 없습니다. 실사용 기록은 이 브라우저에만 남으므로, 참여자 동의와 백업을 별도로 확인해야 합니다.

운영 절차와 준비된 문구는 [첫 고객 실행서](FIRST_CUSTOMER_RUNBOOK_2026-09-28-v01.md), 기능 기준은 [PRD v09](PRD_PROOFLINE_2026-09-28-v09.md)에 있습니다.

검사: `node --check script.js`, `node check.cjs`. 실제 브라우저 렌더링·클릭은 로컬 파일 자동 접근 제한으로 확인하지 못했습니다.
