# PROOFLINE PRD v09 — 첫 고객 모집과 운영 연결

작성일: 2026-09-28. [v08 첫 제안 동행 PRD](../proofline-2026-09-28-v08/PRD_PROOFLINE_2026-09-28-v08.md)를 이어받습니다. 기존 디자인과 v08의 방향 카드·첫 제안·반응 기록을 보존합니다. 유료화는 추후 결정합니다.

## 해결할 빈 부분

v08에는 상담을 시작한 뒤의 작업 흐름이 있지만 **첫 실제 참여자를 어떻게 모집하고, 동의를 확인해 상담 기록으로 넘길지**가 화면에 없었습니다. v09는 첫 고객 모집 문구와 실제 후보 기록을 앞에 연결합니다. 실제 채널이나 고객을 자동으로 만들어내지는 않습니다.

## 첫 시험 대상과 약속

누군가에게 도움이 된 경험은 있으나 자기소개와 첫 제안으로 설명하기 어려운 개인을 먼저 시험합니다. 약 45분의 상담을 통해 강점의 근거와 제안 문구를 함께 만들고, 고객이 선택하면 한 번 직접 알려본 뒤 7~14일 안에 반응을 돌아봅니다. 무료 시범이며 문의·판매를 보장하지 않습니다.

## 구현 범위

| 요구 | 완료 조건 |
| --- | --- |
| 모집 문구 | 화면에서 읽고 복사할 수 있으나 복사는 발송으로 표시하지 않음 |
| 실제 후보 등록 | 가명·고민·직접 경험·알게 된 경로를 기록하고 참여자에게 기기 보관을 설명해 동의받았는지 확인 |
| 후보 → 상담 연결 | 후보에서 상담 시작을 누르면 이야기 단계에 입력이 채워짐. 상담 기록 저장 시 후보와 연결됨 |
| 진행 상태 | 상담 전, 상담 기록, 방향 카드, 첫 제안, 실제 실행의 단계가 기존 저장 자료에 따라 표시됨 |
| 가상과 실제 구분 | 가상 박다은 사례는 실제 후보 목록과 실사용 통계에 포함되지 않음 |
| 가상 운영 시연 | 모집 답장 → 상담·기록 동의 가정 → 첫 제안 실행 가정 → 반응 후 수정 과정을 화면에 표시하고, 상세 카드·제안과 연결 |
| 보관·삭제 | 실제 후보는 이 브라우저에만 최대 20명 보관. 후보와 상담 기록은 각각 삭제 가능하며 서로 자동 삭제되지 않음을 안내 |

## 범위 밖과 남은 조건

공개 주소, 외부 신청 전송, 예약, 제3자 메시지 발송, 실제 고객 대화와 게시, 계정·기기 동기화는 제공하지 않습니다. 모집할 실제 사람 또는 소유한 채널이 있어야 실제 운영이 시작됩니다. 참여자 기록·공개 범위는 고객이 결정하며, 앱이 동의나 외부 경험의 사실을 자동 검증하지는 않습니다.

## 확인할 지표

실제 후보 수, 실제 상담을 시작한 수, 본인이 제안을 이해한 수, 실제 알린 수, 확인된 반응·문의와 운영 시간을 확인합니다. 단일 시범 사례로 일반적인 성공률을 주장하지 않습니다.
