# PROOFLINE v12

비공개 Sites의 기존 주소에 반영할 소스입니다. [`dist/index.html`](dist/index.html)은 배포 화면이며, [`PRD_PROOFLINE_2026-10-01-v12.md`](PRD_PROOFLINE_2026-10-01-v12.md)에 변경 기준을 적었습니다.

첫 화면의 **내 이야기로 시작하기**에서 본인의 경험·강점 후보·첫 대상과 상황·작은 활동을 적으면 방향 카드 초안을 만듭니다. 이어 **첫 제안 만들기**에서 시간·결과물·제외 범위를 정하고, 실제로 알린 뒤 확인한 반응을 기록합니다. **가상 사례 보기**는 별도 시연입니다.

화면 아래 **이 브라우저의 기록 → 기록 백업·복원**에서 파일을 저장하고 다시 불러올 수 있습니다. 이 파일에는 개인 이야기가 담깁니다. 기존 기록은 덮어쓰지 않습니다.

검사: `node --check dist/script.js`, `node check.cjs`. 정적 사이트는 빌드 과정이 없습니다. 실제 고객 반응과 사용자 화면의 최종 클릭 확인은 별도입니다.
