# PROOFLINE PRD v08 — 첫 제안 동행

작성일: 2026-09-28. [기존 서비스 방향과 창업자 배경](../proofline-2026-09-26-v02/PRD_PROOFLINE_2026-09-26-v04.md), [v07의 이야기·근거·후속 기록](../proofline-2026-09-26-v07/PRD_PROOFLINE_2026-09-26-v07.md)을 이어받습니다. 기존 화면의 색, 글꼴, 전체 배치는 유지합니다. 유료화는 추후 결정합니다.

## 한 문장 약속

경험은 있지만 자신을 누구에게 어떻게 알릴지 막힌 사람이 **상담을 통해 첫 제안 문구를 만들고, 본인이 선택한 한 채널에서 실제로 제안한 뒤, 받은 반응으로 고칩니다.** 게시·문의·매출은 보장하지 않습니다.

## 첫 시범 대상과 역할

- 첫 시범 대상: 경험이나 전문성은 있으나 자기소개와 첫 제안을 만들기 어려운 개인. 전체 비전의 대상을 이 집단으로 영구 제한하지 않습니다.
- 고객: 경험과 사실을 확인하고 제안 문구 및 공개 범위를 승인한 뒤, 채널을 선택해 직접 게시·전달합니다.
- 운영자: 이야기를 듣고 경험의 근거, 대상, 불편, 제안, 문구, 반응을 함께 정리합니다. 외부 자료와 주장의 사실 여부를 별도로 확인합니다.
- 앱: 이 과정의 초안, 제안 버전, 실행 날짜와 장소, 반응, 운영 시간을 해당 브라우저에 기록합니다. 자동 게시·고객 연락·자동 알림은 하지 않습니다.

## 한 번의 서비스 흐름

| 단계 | 운영자가 하는 일 | 고객이 확인하는 것 | 화면 결과 |
| --- | --- | --- | --- |
| 1. 대화 | 45분 내외로 경험·근거·중요 조건을 듣기 | 강점 해석이 자신의 말과 맞는지 | 방향 카드 |
| 2. 제안 | 대상 한 부류, 불편, 작은 도움, 채널 한 곳, 요청할 행동을 정리 | 표현과 공개 범위를 승인 | 첫 제안 문구 1차 |
| 3. 실제 알리기 | 문구를 복사·전달하도록 돕되 게시를 대행한 것으로 표시하지 않기 | 본인이 선택한 곳에 직접 게시·전달 | 실행 날짜·장소 기록 |
| 4. 반응 확인 | 실제 들은 말과 문의 수를 확인. 미확인은 0으로 쓰지 않기 | 반응을 해석하고 수정 방향 선택 | 제안 2차와 실행 이력 |

처음은 무료 시범으로 운영하고, 한 사람의 상담부터 제안·실행·수정까지 걸린 시간을 기록합니다. 5명 정도의 소규모 시범 후 질문 이해, 실제 실행, 반복되는 도움 요청을 검토합니다. 소규모 수치를 시장 수요나 매출 효과로 단정하지 않습니다.

## v08 구현 범위와 완료 기준

1. 기존 방향 카드를 열어 첫 제안의 대상·불편·도울 변화·작은 활동·채널·요청 행동을 적을 수 있습니다.
2. 입력을 바탕으로 문구 초안을 만들고 사람이 수정해 저장할 수 있습니다. 저장할 때마다 새 제안 버전을 남기며 1차·2차를 비교할 수 있습니다.
3. 문구 복사와 실제 실행 기록을 분리합니다. 실제 실행 날짜·장소·고객의 문구 검토 동의를 입력해야 실행으로 기록합니다. 미래 날짜는 차단합니다.
4. 반응·문의 수는 미확인과 확인된 0을 구분합니다. 같은 실행 기록을 나중에 갱신할 때 이전 기록은 이력으로 남깁니다.
5. 방향 카드, 제안 버전, 실행·반응을 전체 텍스트로 내려받을 수 있습니다. 가상 사례는 시범 운영 현황 숫자에서 제외합니다.
6. `index.html` 첫 방문에서 가상의 박다은 사례를 열어 1차 제안 → 가상 실행과 반응 → 좁힌 2차 제안을 볼 수 있습니다. 가상 데이터는 실제 성과가 아닙니다.

## 운영·보관 한계

브라우저 내부 저장에 최대 20명까지 기록합니다. 사이트 데이터를 지우거나 다른 기기를 쓰면 기록이 보이지 않을 수 있으므로, 실제 시범에서는 고객 동의 범위에 맞춰 전체 시범 기록을 따로 저장해야 합니다. 계정, 공동 작업, 예약, 메시지 전송, 실제 게시, 자동 분석, 결제는 구현하지 않았습니다. 외부 자료의 진위와 개인의 경험은 자동 검증하지 않습니다. 실제 개인정보를 기록·공개하기 전 고객 동의를 확인합니다.

## 다음 검증 질문

- 고객이 자신의 제안을 자기 말로 설명할 수 있습니까?
- 고객이 본인이 선택한 채널에서 실제로 한 번 알렸습니까?
- 받은 반응이 대상·불편·제안의 어느 부분을 바꾸게 했습니까?
- 운영자가 한 사람에게 쓴 시간이 반복 가능한 수준입니까?

현재는 실제 시범 고객이 없으므로 위 결과는 아직 측정되지 않았습니다.
