# PROOFLINE v08 — 첫 제안 동행 시연

[`index.html`](index.html)을 열면 가상의 박다은 사례가 바로 보입니다. 위쪽 방향 카드와 아래쪽 **첫 제안 동행**에서 1차·2차 문구를 바꿔 보세요. 가상 실행·반응은 오른쪽 실행 이력에 표시됩니다. 화면이 보이지 않으면 [`fictional-pilot-v08.txt`](fictional-pilot-v08.txt)에서 같은 흐름을 읽을 수 있습니다.

새 기록에서는 **이야기 → 강점·방향 카드 → 첫 제안 문구 → 고객의 실제 게시·제안 → 반응·수정** 순서로 진행합니다. 카드 내용을 바탕으로 문구 초안을 만들 수 있지만 대상의 불편과 도울 변화는 사람과 함께 확인해 적습니다. **제안 문구 복사**는 게시나 전송을 하지 않습니다. 실제로 알린 뒤에만 날짜·장소와 고객 승인 여부를 기록합니다.

이 시연의 인물·게시·반응·숫자는 모두 허구입니다. 실제 시범 이용자와 실제 성과는 아직 없습니다. 시범 운영 현황은 가상 사례를 제외하고 표시합니다. 기록은 현재 브라우저에만 저장되며 다른 기기 동기화, 자동 알림, 실제 메시지 전송, 자동 게시 기능은 없습니다. 이전 v07의 실제 기록을 읽어올 수 있지만 원본 저장 값은 지우지 않습니다.

기획은 [`PRD_PROOFLINE_2026-09-28-v08.md`](PRD_PROOFLINE_2026-09-28-v08.md), 실제 시범 진행 순서와 안내 문구는 [`PILOT_OPERATIONS_2026-09-28-v01.md`](PILOT_OPERATIONS_2026-09-28-v01.md)에 있습니다. 유료화는 추후 결정합니다.

검사: `node --check script.js`, `node check.cjs`. 로컬 파일의 실제 브라우저 렌더링·클릭은 이 환경의 접근 제한으로 자동 확인하지 못했습니다.
