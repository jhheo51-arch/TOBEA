# PROOFLINE PRD v07 — 상담을 시작하고, 근거를 구분하고, 행동으로 이어가기

작성일: 2026-09-26. [서비스 방향·창업자 배경이 담긴 PRD v04](../proofline-2026-09-26-v02/PRD_PROOFLINE_2026-09-26-v04.md)와 [v05 구현 범위](../proofline-2026-09-26-v05/PRD_PROOFLINE_2026-09-26-v05.md)를 이어받습니다. 유료화는 추후 결정합니다. 기존 v02의 색·타이포그래피·레이아웃은 유지합니다.

## 제품이 해결할 일

자신의 경험을 어떻게 설명하거나 다음 활동으로 연결해야 할지 모르는 사람이 상담자와 대화하면서 **직접 해본 일 → 강점 가설 → 가능한 방향 → 자기소개와 첫 행동 → 반응을 반영한 수정**으로 나아갑니다. 상담자는 강점과 방향을 판단하고, 앱은 질문·근거·결과·수정 이력을 정리합니다. 앱이 자동으로 진로를 판정하거나 성과를 보장하지 않습니다.

## 이번 버전의 세 가지 개선

| 개선 | 이용자에게 보이는 동작 | 완료 기준 |
| --- | --- | --- |
| 시작 질문 단순화 | 처음에는 가명·고민·직접 해본 일만 필수로 작성. 강점과 방향은 다음 단계에 표시 | 강점·방향을 몰라도 이야기 카드 저장 가능 |
| 근거와 해석 구분 | 카드와 텍스트 저장본에 본인 진술, 상담 해석, 외부 자료의 입력 출처를 구분. 강점 해석에 대한 본인 반응 기록 | 정보의 성격을 카드에서 식별 가능. 출처 정보가 모자라면 조사 전 표시 |
| 실행 후 재방문 | 첫 행동을 돌아볼 날짜, 실행 상태, 실제 행동·반응·수정·다음 행동 기록. 이전 버전과 전체 이력 저장 | 같은 사람의 새 카드 버전으로 기록되고 다시 열어 비교 가능 |

## 흐름과 주요 규칙

1. **이야기:** 필수 3개와 선택 조건 1개로 시작합니다. 이때 강점·방향은 빈 상태로 저장할 수 있습니다.
2. **강점·방향:** 상담자가 강점과 근거, 최대 두 방향과 이유, 자기소개·작은 활동·첫 행동을 함께 적습니다. 강점과 근거 또는 두 번째 방향과 이유는 쌍으로 작성합니다. 돌아볼 날짜는 7일 뒤를 제안하며 수정할 수 있습니다.
3. **해본 뒤:** 첫 행동을 해봤다면 행동과 들은 반응을 모두 적습니다. 아직 못 했다면 다음에 해볼 일을 적습니다. 저장하면 같은 기록의 새 카드로 남습니다.
4. **근거:** 출처 이름·웹 주소·확인 날짜·관련 내용이 모두 있어야 외부 자료를 카드에 표시합니다. 이는 출처를 *입력했다는 뜻*이며 내용의 진위나 개인에게 맞는 방향을 검증했다는 뜻은 아닙니다.
5. **보관:** 브라우저의 기기 내 저장 공간을 사용합니다. 기존 v05/v06 기록을 읽되 원본 저장 데이터를 지우지 않습니다. 개별 카드와 전체 카드 이력을 텍스트로 내려받을 수 있습니다. 자동 알림·로그인·기기 간 동기화는 제공하지 않습니다.

## 가상 사례와 실제 검증

가상의 박다은 사례는 첫 방향 카드와 반응 후 수정 카드 두 버전으로 보여줍니다. 인물과 경험·반응은 허구이며 참고 외부 자료는 가상 사례의 시장 수요를 입증하지 않습니다. 실제 이용자에게는 질문을 시작할 수 있는지, 각 정보의 성격을 이해하는지, 첫 행동 후 다시 돌아오는지를 관찰해야 합니다. 현재 시제품에는 실사용 성과 데이터가 없습니다.
