# PROOFLINE — 경험을 제안으로

## 사업 아이디어

경험은 있지만 자신을 어떻게 소개하고 어떤 서비스를 팔지 막막한 1인 전문가를 위한 **증거 기반 브랜딩 컨설팅**입니다. 고객의 사례를 먼저 듣고, 고객이 실제로 해결해 온 문제를 한 문장과 작은 첫 서비스로 정리합니다.

첫 고객 가설은 독립을 준비하는 기획자·연구자·코치 등입니다. 실제 고객 수요와 가격은 아직 검증되지 않았습니다.

## 이번에 만든 것

`index.html`을 열면 질문에 답해 브랜드 문장, 근거, 첫 서비스 제안, 고객 인터뷰 질문을 한 장으로 만들 수 있습니다. 예시 채우기, 내용 복사, 텍스트 파일 저장, 입력 지우기가 작동합니다. 입력 내용은 현재 브라우저의 로컬 저장소에만 저장되며 외부 서버로 전송하지 않습니다. 글꼴을 불러올 때만 Google Fonts에 접속할 수 있습니다.

문장 생성은 미리 정한 규칙으로 작동합니다. 생성형 AI를 연결하거나 성과를 자동 검증하지 않습니다. 사실이 확인되지 않은 수치를 새로 만들지 않습니다.

## 컨설팅 서비스 가설

1. 발견 인터뷰: 고객의 경험, 반복해서 해결한 문제, 확인 가능한 사례를 수집합니다.
2. 제안 설계: 브랜드 문장과 첫 서비스 범위, 소개 자료를 만듭니다.
3. 시장 검증: 잠재 고객 3명에게 제안을 보여주고 문제의 시급함과 비용 지불 의사를 확인합니다.

첫 유료 상품은 **2주 집중 설계**를 가정합니다. 인터뷰 2회와 브랜드 한 장, 첫 서비스 소개서, 고객 검증 질문지를 제공하는 형태입니다. 기간과 구성은 가설이며 실제 인터뷰 후 조정해야 합니다. 가격은 임의로 정하지 않았습니다.

## 다음 검증

독립을 준비하는 전문가 3명에게 시제품을 써보게 하고, 어떤 질문이 어려웠는지, 결과물을 실제 소개에 쓰고 싶은지 확인합니다. 이어서 결과물을 볼 잠재 고객 3명에게 서비스 설명이 이해되는지 묻습니다. 구매 의사는 실제 대화로 확인해야 합니다.
