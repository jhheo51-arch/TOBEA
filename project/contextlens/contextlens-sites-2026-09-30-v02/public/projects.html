과제 자료의 원문 근거·반례 연결

다른 개선 후보와 우선순위 비교

영향·확신·노력을 1~5로 평가합니다. 영향×확신÷노력은 참고 점수이며, 근거와 선택 이유를 함께 적습니다.

변경을 실행 가능한 형태로

흐름은 단계별로 적습니다. 예: 제안 읽기 → 댓글 찾기 → 근거 검토. 계획과 실제 반영 내용을 구분하세요.

전후 흐름·실제 변경 기록 수정
기능 정의·운영 기준·내 역할

실제 화면·기능 정의서는 제출 문서에 기록됩니다. 완료일은 기능이 실제 반영된 날짜를 적습니다.

어떤 변화가 관찰됐나요?

값 0과 미측정은 다릅니다. 전후 기간·대상·집계 방법을 같게 정하고 출처를 적어 주세요.

실제 참가자 시험 진행

역할과 결정 과정을 남기기

직무 역할별 요청을 설계하고, 실제로 받은 피드백과 결정 이유를 남깁니다. 계획만 작성한 항목은 실제 협업으로 집계하지 않습니다.

저장한 HTML 파일을 열고 ‘인쇄 · PDF로 저장’을 누르면 지원서용 파일로 저장할 수 있습니다. 비공개 Sites 주소는 소유자만 볼 수 있습니다.
