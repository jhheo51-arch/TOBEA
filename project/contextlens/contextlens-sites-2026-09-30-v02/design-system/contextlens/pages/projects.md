# 개선 프로젝트 화면 기준

기존 ContextLens의 네이비·금색·밝은 배경과 Noto Sans KR 우선 글꼴을 이어 사용한다. ui-ux-pro-max 검색에서 확인한 폼 라벨·저장 피드백·입력 종류 지침을 적용한다. 자동 추천한 포트폴리오/게이트웨이 화면 패턴은 작업 공간의 목적에 맞지 않아 적용하지 않는다.

- 첫 화면에 자료 선택, 저장 상태, 5개 작업 단계를 보여 준다. 큰 소개 영역을 만들지 않는다.
- 근거·반례 목록과 후보 비교는 펼쳐 확인한다. 모바일의 완성 체크는 접혀 시작한다.
- 입력 항목마다 보이는 라벨을 연결하고 숫자·날짜·주소 입력 종류를 구분한다.
- 저장 중·성공·실패 상태를 표시하고, 저장 실패 시 입력을 보존한다.
- 버튼은 44px 이상, 키보드 초점을 표시하고 색만으로 완료 상태를 전달하지 않는다.
- 원문 댓글은 콘텐츠 이용 경험의 단서이고, 서비스 자체의 문제 근거와 구분한다.
- 숫자가 없는 상태를 0으로 바꾸지 않는다. 모든 문서에 기록 수준과 한계를 남긴다.
