# ContextLens v01

유튜브 영상 또는 뉴스 기사 링크 하나를 넣어 **원문 맥락을 먼저 확인한 뒤 공개 댓글의 반복 표현과 질문·불편 후보**를 보는 로컬 도구입니다. 첫 사용 대상은 유튜브입니다.

## 실행

Windows에서 [실행하기.cmd](./실행하기.cmd)를 두 번 클릭합니다. 브라우저가 `http://127.0.0.1:8765`를 엽니다. 검은 실행 창을 닫으면 도구가 종료됩니다. 첫 실행에는 필요한 공개 소프트웨어를 설치하므로 인터넷 연결이 필요합니다. Python 3이 설치되어 있어야 합니다.

브라우저가 자동으로 열리지 않으면 주소창에 `http://127.0.0.1:8765`를 입력합니다. `127.0.0.1`은 현재 컴퓨터만 가리키는 주소이며 인터넷에 게시된 사이트가 아닙니다.

## 사용 흐름

1. 공개 유튜브 영상 URL 또는 뉴스 기사 URL 하나를 넣고 **맥락부터 분석하기**를 누릅니다.
2. 결과 상단에서 본문/자막과 댓글이 실제 확보되었는지 확인합니다.
3. `원문 맥락 → 댓글의 반응 → 개선할 문제 후보 → 근거 댓글 → 해석의 한계` 순서로 읽습니다.
4. **내 판단 남기기**에 직접 확인한 내용과 개선 가설을 적습니다. **요약 저장**은 Markdown 문서를, **자료 저장**은 분석 자료 JSON 파일을 내려받습니다. 다운로드 이름에는 날짜와 시간이 포함됩니다.

## 가능한 범위

- 유튜브: 공개 단일 영상의 제목·설명·접근 가능한 자막과 최신 공개 댓글 최대 100개. 자막이 없거나 공개 접근이 막히면 원문 맥락 분석은 하지 않습니다.
- 뉴스: 공개 HTML 기사 본문. 댓글이 페이지 HTML·구조화 데이터에 포함된 경우, 또는 가디언 공개 Discussion API가 제공되는 경우에 수집합니다. 그 밖의 별도 로그인·동적 로딩 댓글은 자동 수집되지 않습니다.
- **직접 붙여 넣기**는 자동 수집 실패 때 사용하는 보조 경로입니다. 제목·본문·댓글을 입력하면 같은 규칙으로 분석합니다.

반복 표현은 같은 문제가 반복됐다는 확정 판단이 아닙니다. 댓글의 질문·불편 유형은 규칙으로 찾은 후보입니다. 개선 효과, 전체 시청자 비율, 상담 성과는 이 결과로 확인할 수 없습니다.

## 자료 보관

자료는 현재 컴퓨터의 브라우저에서 표시됩니다. 서버는 입력 링크와 댓글을 로그로 저장하지 않습니다. **자료 저장**으로 내려받은 JSON에는 공개 댓글 원문이 들어가므로 개인적으로 보관하고, 외부 공유 시 작성자를 식별할 수 있는 정보와 긴 원문 인용을 제거합니다.

## 구성

- [PRD](./PRD_CONTEXTLENS_2026-09-30-v01.md): 목표·범위·성공 기준
- `extractors.py`: 공개 유튜브·뉴스 자료 수집
- `analysis.py`: 원문 문장 추출, 댓글 분류와 반복 표현 계산
- `app.py` 및 `static/`: 로컬 서버와 화면

이 결과물은 첫 버전입니다. 공개 사이트 구조가 바뀌면 추출이 실패할 수 있으며, 그때는 실패 사실을 표시하고 직접 붙여 넣기 경로를 사용할 수 있습니다.
