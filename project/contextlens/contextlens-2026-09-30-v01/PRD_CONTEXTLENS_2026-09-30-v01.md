# PRD: 맥락 먼저, 댓글 나중에 — ContextLens v01

작성일: 2026-09-30 · 대상: 혼자 CX 조사 경험을 쌓는 사용자 · 우선순위: 유튜브 먼저, 뉴스 확장

## 1. 문제와 목표

댓글만 모아 단어 빈도를 세면 영상·기사의 주제와 주장, 댓글이 반응하는 지점, 실제 경험과 추측을 혼동하기 쉽다. 사용자가 공개 유튜브 또는 뉴스 링크 **하나**를 넣으면 먼저 원문 맥락을 수집하고, 그 다음 공개 댓글을 분석해 반복되는 반응과 개선할 문제 후보를 보여준다. 결과는 로컬 파일로 저장해 회차별 경험을 쌓는다.

## 2. 사용자 흐름

1. 첫 화면에서 유튜브 또는 뉴스 URL 하나를 입력하고 분석을 누른다.
2. 화면은 공개 자료를 가져오는 중인지, 분석 중인지 진행 상태를 보여준다.
3. 결과 상단에서 **무엇을 읽었는지** 확인한다: 제목·출처·설명, 자막 또는 기사 본문 확보 여부, 댓글 수·선택 기준·수집 시각.
4. ‘원문 맥락’에는 본문에서 추출한 핵심 문장과 분석 기준이 표시된다.
5. ‘댓글 반응’에는 반복 표현과 댓글 수가 표시된다. 근거 영역에는 수집 댓글 중 최대 40개의 원문 일부와 원문 본문에 겹치는 표현이 표시된다. 반대·보완 관점은 사용자가 근거 댓글을 읽고 직접 기록한다.
6. 사용자는 원문에서 직접 확인한 핵심, 반복 문제와 반례, 개선 가설, 다음 검증 방법을 메모하고 결과를 JSON/Markdown으로 저장한다. 저장한 결과에는 출처와 분석 한계가 포함된다.

## 3. 범위

### 이번 버전에 포함

- 공개 유튜브 단일 영상: 메타데이터·설명, 접근 가능한 자막, 공개 댓글 최대 100개를 가져온다. 영상 파일 자체는 저장하지 않는다.
- 공개 뉴스/기사: HTML에 공개된 제목·본문과 **본문 HTML 또는 구조화 데이터에 포함된 댓글**을 가져온다. 가디언 기사는 공식 공개 Discussion API에서 댓글을 가져온다.
- 자막/본문의 문장과 키워드를 먼저 추출하고, 댓글을 정리한 뒤 반복 주제를 묶는다.
- 각 결과에 `직접 확인한 자료 / 자동 추출한 해석 / 확인할 수 없는 정보`를 구분한다.
- 원문·댓글 취득 실패, 자막 없음, 뉴스 댓글의 별도 로그인·스크립트 로딩 등 확인 가능한 사유를 표시한다. 댓글 비활성화와 일시적인 접근 실패를 구별할 수 없으면 단정하지 않는다.
- 로컬에서 실행하고, 사용자가 넣은 URL의 공개 자료만 요청한다. 분석 결과를 외부 AI 서비스에 보내지 않는다.

### 이번 버전에 포함하지 않음

- 계정 로그인, 비공개·유료 콘텐츠, 모든 뉴스 사이트의 댓글 보장, 영상 음성 인식, 정확한 감정 판정, 조회자 전체를 대표하는 통계.
- 임의의 댓글을 ‘고객 문의’나 ‘실제로 해결된 문제’로 단정하는 기능.
- 회사의 실제 문의량·SLA·CSAT 개선을 입증하는 기능.

## 4. 핵심 분석 기준

- **원문 맥락**: 자막 또는 기사 본문이 확보되면 제목·설명보다 우선한다. 없으면 ‘원문 맥락 미확인’으로 표시하고 완전한 맥락 분석을 하지 않는다.
- **분석 단위**: 댓글 1개. 답글은 첫 버전에서 별도 수집하지 않는다. 삭제·수정·정렬에 따라 결과가 달라질 수 있다.
- **반복**: 정규화한 같은 단어가 나타난 댓글 수와 `분석한 댓글 수`를 함께 제시한다. 의미가 비슷한 다른 표현을 자동으로 같은 주제로 묶지는 않는다. 빈도가 높다는 것이 전체 시청자·독자 비율을 뜻하지 않는다.
- **주장과 경험 분리**: 댓글을 직접 경험, 질문형 표현, 불편·문제 표현, 정보 보완, 의견·반응 중 가능한 유형으로 분류하되 규칙 기반의 후보라고 표시한다. 실제 경험 여부와 수사적 질문 여부는 사람이 판단한다.
- **CX 개선 후보**: 질문·불편 댓글이 많은 지점을 안내 문구, 콘텐츠 구성, 도움 경로의 가설로 제안한다. 콘텐츠 제작자·서비스가 실제로 수정했다는 뜻은 아니다.

## 5. 기술 설계

- Python 로컬 서버와 브라우저 화면. 공개 영상 데이터는 `yt-dlp`, 뉴스 HTML은 `urllib`+`BeautifulSoup`로 읽는다.
- 분석은 로컬의 재현 가능한 규칙 기반 처리로 시작한다. 키워드·문장 추출·댓글 묶음을 사람이 검토할 수 있도록 원자료의 짧은 근거와 함께 보여준다.
- 입력 URL은 `http/https`의 공개 주소만 허용하고, 로컬/사설 네트워크 주소는 차단한다.
- 기본 수집은 최대 100댓글, 길이 제한·요청 시간 제한을 둔다. 원본 영상·음성·개인 연락처를 저장하지 않는다.
- 서버에 API 키가 없어도 동작하도록 설계한다. 공개 데이터 접근이 막히면 이유를 표시하고, 사용자가 가진 자막·댓글을 붙여 넣어 같은 분석을 실행하는 보조 경로를 제공한다.

## 6. 성공 기준과 확인 방법

1. 공개 유튜브 URL 1개 입력만으로 제목·설명, 접근 가능 자막, 공개 댓글을 가져와 원문 맥락과 댓글 분석을 순서대로 표시한다.
2. 자막이나 댓글이 없는 링크에서는 내용을 지어내지 않고 부분 결과와 부족한 자료를 표시한다.
3. 일반 뉴스 HTML에서 본문을 읽고, 댓글이 HTML에 있을 때만 분석한다. 없으면 ‘댓글 접근 불가’로 표시한다.
4. 분석 결과의 건수·출처·수집 시각·해석 한계가 화면과 내보낸 파일에 남는다.
5. 키보드로 입력·실행·결과 읽기·저장을 할 수 있고, 작은 화면에서도 가로 스크롤 없이 읽힌다.

## 7. 알려진 외부 제약

유튜브 공식 API는 댓글 조회에 인증이 필요하고, 공식 자막 내려받기는 권한 있는 OAuth 요청이 필요하다. 공개 추출기는 사이트 변경에 따라 실패할 수 있다. 뉴스 댓글은 사이트마다 별도 시스템·로그인·동적 로딩을 사용하므로 임의의 기사 링크에서 모두 수집할 수 없다. 가디언 공개 Discussion API는 지원하지만 댓글이 닫힌 기사에서는 자료가 없다. 이 제품은 접근 실패를 숨기지 않는다.
