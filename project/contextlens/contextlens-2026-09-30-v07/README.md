# ContextLens v07

공개 유튜브 영상·뉴스 기사의 원문과 댓글을 함께 읽고, 관찰 → 욕구 후보 → 개선 실험 → 재확인을 기록하는 로컬 CX 연구 도구입니다.

v07에서는 한글 댓글을 오래 읽기 쉽도록 Noto Sans KR을 우선 적용하고 제목·댓글·입력칸의 크기, 굵기, 줄 간격을 조정했습니다. 이 글꼴이 없는 기기에서는 운영체제 기본 글꼴을 사용하며, 외부 글꼴 서버 연결은 필요하지 않습니다.

## 분석 순서

1. 링크를 넣어 원문·댓글·표본 범위를 확인합니다. 링크 수집이 막히면 보유한 공개 자료를 직접 붙여 넣을 수 있습니다.
2. **판단**에서 분석할 사람, 이용 단계, 바꿀 수 있는 경험, 분석 질문을 적습니다. 공개 댓글 작성자를 모두 고객으로 가정하지 않습니다.
3. **댓글**에서 각 댓글을 근거·반례·관련 낮음으로 검토하고 자동 분류를 수정합니다. 원래 자동 분류 결과는 별도로 남습니다.
4. **제안**에서 원문 맥락과 댓글 사례를 보고 욕구 후보와 다음 제공물을 검토합니다. 영상 유형과 뉴스에 따라 제안 문구가 달라집니다.
5. **검증**에서 실제 변경, 관찰할 지표, 변경 전후 값, 다른 설명을 기록합니다. 같은 링크를 다시 분석하면 수집 시점을 비교할 수 있습니다.

기록은 `../contextlens-data/cases.sqlite3`에 보관됩니다. 새 버전 폴더로 넘어가도 같은 컴퓨터에서는 기록이 이어집니다. **자료 저장**은 원문·전체 수집 시점·수정 기록이 포함된 JSON 파일, **요약 저장**은 읽기 쉬운 Markdown 파일입니다. 기존 v05 브라우저 메모는 같은 링크를 처음 다시 분석할 때 통합 기록으로 복사됩니다.

## 실행

이 폴더의 `실행하기.cmd`를 열거나, 가상환경에서 `python app.py`를 실행한 뒤 `http://127.0.0.1:8766/`을 여세요. 필요한 패키지는 `requirements.txt`에 있습니다.

## 해석 주의

자동 분류와 욕구 카드는 탐색용 후보입니다. 두 번 이상 비슷한 표현이 있어야 카드를 만들지만, 전체 이용자의 비율이나 만족도는 알 수 없습니다. 최신순·인기순은 무작위 표본이 아니며 수집 시점별 댓글 수가 달라져도 개선 효과를 뜻하지 않습니다. 자막·뉴스 댓글이 확보되지 않거나 다른 언어를 자동 해석하지 못하면 화면의 한계를 확인하고 직접 검토하세요.

## 확인

`python -m unittest -v test_contextlens.py`로 핵심 분석과 저장을 확인할 수 있습니다.
