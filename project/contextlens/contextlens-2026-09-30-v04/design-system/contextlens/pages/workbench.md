# ContextLens 분석 작업 화면

`MASTER.md`의 차분한 색과 글자 중심 원칙을 적용한다. 이 화면은 뉴스레터 구독 페이지가 아닌 분석 작업 공간이므로 전환형 히어로·구독 문구는 적용하지 않는다.

- 흐름: 분석 대상 → 원문 맥락 → 댓글 반응 → 표본·언어 범위 → 사용자 욕구와 제공물 → 근거 댓글 → 내 판단.
- 사실, 자동 분류, 해석 후보, 실험 제안을 제목과 짧은 설명으로 구분한다. 숫자는 표본의 범위를 함께 보여 준다.
- 넓은 화면은 결과 옆에 메모를 고정한다. 1050px 이하에서는 결과 폭을 확보하고 메모로 바로 이동할 수 있는 링크를 제공한다.
- 소개글, 자동 추출 문장, 근거 댓글 예시는 사용자가 펼쳐 볼 수 있게 한다. 중요한 상태와 검토 필요 건수는 처음부터 보인다.
- 본문 16px, 보조 설명 14px, 상태 12px 이상을 기준으로 하며, 키보드 초점 표시와 동작 감소 설정을 유지한다.
