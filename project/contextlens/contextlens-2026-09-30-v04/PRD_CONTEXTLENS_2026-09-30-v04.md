# ContextLens v04 — 분석 작업 화면 개선

## 목표

링크를 넣은 뒤 자료의 범위와 한계를 먼저 파악하고, 반복 반응에서 고객의 욕구 후보와 다음 제공물을 검토하며, 자신의 판단을 남길 수 있게 한다.

## 발견한 문제

v03의 약 646px 화면에서는 결과와 메모가 좁은 두 열에 들어가 글줄이 과도하게 꺾였다. 영상 소개글과 자동 자막, 욕구 카드의 댓글 예시가 처음부터 모두 펼쳐져 핵심 판단까지 내려가는 거리가 길었다. 화면 상단에는 수집 범위와 검토 필요 건수가 요약되지 않았다.

## 구현 범위

1. 결과 상단에 원문 상태, 수집 댓글 수, 직접 검토할 댓글 수를 보여 준다.
2. 원문·표본·욕구·근거·메모로 이동하는 메뉴를 제공한다. 유튜브 전용 구역은 뉴스 결과에서 메뉴에도 표시하지 않는다.
3. 소개글, 자동 추출 문장, 욕구 카드의 댓글 근거를 펼쳐 읽는다. 확인해야 할 사실과 제안은 기본 화면에 남긴다.
4. 넓은 화면에서 메모를 오른쪽에 두고, 1050px 이하에서는 결과와 메모에 충분한 너비를 준다.
5. 기존 메모 저장 방식과 분석·파일 저장 기능을 유지한다.

## 판단 기준

- 자동 자막은 자료 출처로 표시하고, 영상 화면이나 음성을 직접 분석했다고 표현하지 않는다.
- 수치는 수집된 표본의 건수로 적는다. 자동 분류하지 못한 언어 댓글 수를 별도로 드러낸다.
- 욕구는 해석 후보, 다음 제공물은 시험할 가설임을 화면에서 구분한다.

## 확인 결과

- 실제 유튜브 링크 `JYUilbw34Z0`으로 분석한 결과, 수집 댓글 195개와 직접 검토 2개가 요약에 표시됐다. 수집 시각에 따라 숫자는 달라진다.
- 기존 네 가지 판단 메모가 새 버전 화면에 복원됐다.
- 375px 너비에서 화면 전체의 가로 넘침은 없었고, 메뉴만 가로로 이동할 수 있다.
- 기존 분석 자동 검사 10개와 JavaScript 문법 검사를 통과했다.

## 다음 검증

사용자가 실제 사례를 두세 건 기록하며 메뉴 이동, 근거 펼치기, 메모 작성에 걸리는 시간을 비교한다. 뉴스 링크에서 댓글 접근 실패 시 경고와 직접 입력 흐름이 이해되는지도 확인한다.
