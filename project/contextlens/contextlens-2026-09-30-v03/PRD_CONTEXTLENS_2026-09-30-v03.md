# ContextLens v03: 여러 언어 댓글 대비

## 목표

한국어 외의 공개 댓글이 섞여도 원문을 잃지 않고, **자동으로 해석한 댓글과 직접 읽어야 할 댓글을 구분**합니다. 영어의 반복 행동·요청 표현은 기존 CX 카드에 반영하고, 지원하지 않는 언어를 한국어·영어 규칙으로 억지 분류하지 않습니다.

## 동작

1. 링크로 가져온 댓글 또는 직접 입력한 댓글의 원문을 그대로 보존합니다.
2. 한글·라틴 문자·일본어 가나·한자·그 밖의 문자와 일부 영어 단어를 보고 언어 **단서**를 붙입니다. 정확한 언어 판별이나 자동 번역이라고 주장하지 않습니다. 한자만 있으면 중국어로 단정하지 않습니다.
3. 한국어·영어 단서가 충분한 댓글에는 질문·불편 등 표현 규칙과 콘텐츠 욕구 규칙을 적용합니다. 한국어·영어가 함께 있으면 두 규칙을 적용합니다. 영어는 반복 청취, 팬 응원, 가족 공유, 후속 콘텐츠 요청, 노래·무대, 상품·이벤트의 명시적인 표현을 지원합니다.
4. 일본어 문자, 한자만 있는 댓글, 언어 미확인 라틴 문자, 그 밖의 문자·기호만 있는 댓글은 `직접 검토 필요`로 표시합니다. 해당 댓글은 자동 반복 표현·욕구 수치에서 제외하지만 목록과 JSON 저장에는 포함합니다.
5. 결과 화면에 언어 단서별 건수, 자동 분류 대상 수, 직접 검토 필요 수를 표시합니다. 댓글 목록을 정렬과 언어 단서로 걸러 볼 수 있습니다. 반복 표현의 비중은 자동 분류 대상 댓글을 분모로 계산합니다. 직접 검토 대상이 공지 제외 댓글의 20% 이상이면 CX 카드의 우선순위를 보류하라는 안내를 표시합니다.

## 성공 기준과 검증

- 영어 댓글 두 개가 같은 재청취 행동을 말하면 CX 카드에 근거와 함께 포함됩니다.
- 일본어·한자·영어 여부가 불확실한 라틴 문자 댓글은 원문 그대로 보이고 자동 욕구 계산에서 빠집니다.
- URL만 있는 댓글의 `?`는 질문으로 분류되지 않습니다.
- 이전 v02 메모는 같은 로컬 주소의 브라우저 저장소에서 복원됩니다.

## 한계

문자 종류만으로 언어를 완전히 알 수 없습니다. 짧은 영어 감탄사와 영어가 아닌 라틴 문자 문장은 보수적으로 검토 대상이 될 수 있습니다. 영어 표현 규칙도 농담·반어·인용을 이해하지 못합니다. 다른 언어의 번역과 의미 분석은 제공하지 않습니다. 댓글에서 발견한 건수는 수집 표본 안의 표현 수이며 전체 시청자의 욕구 비율이 아닙니다.
