# ContextLens v03

유튜브 영상 또는 뉴스 링크의 원문과 공개 댓글을 함께 살피는 개인 CX 분석 도구입니다. v03에서는 영어 댓글을 일부 분석하고, 다른 언어·언어 미확인 댓글을 별도로 확인할 수 있게 했습니다. 이전 버전 폴더는 보존했습니다.

## 실행

Windows에서 [실행하기.cmd](./실행하기.cmd)를 두 번 클릭합니다. 첫 실행에는 Python 3과 인터넷 연결이 필요합니다. 브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:8766/`을 엽니다. 로컬 주소이므로 현재 컴퓨터에서만 열립니다. 실행 창을 닫으면 도구가 종료됩니다.

## 사용

1. 공개 유튜브 영상 또는 뉴스 URL을 입력하고 **맥락부터 분석하기**를 누릅니다.
2. **댓글 언어 단서와 검토 범위**에서 자동 분류 대상과 직접 검토가 필요한 건수를 확인합니다.
3. **근거 댓글**에서 정렬별 보기와 언어 단서별 보기를 조합해 원문을 확인합니다. ‘직접 검토 필요’ 댓글은 자동 CX 제안에서 빠져 있으므로 해석할 수 있는 사람의 판단을 기록합니다.
4. 오른쪽 **내 판단 남기기**에 관찰·반례·개선 가설을 적습니다. v02와 같은 브라우저·로컬 주소를 사용하므로 기존 메모를 불러옵니다.

한국어·영어 단서는 확정된 언어 판별이 아닙니다. 일본어 문자·한자만 있는 댓글·언어 미확인 라틴 문자 등은 원문을 남기되 자동 의미 분석하지 않습니다. 자동 번역은 제공하지 않습니다. [기획서](./PRD_CONTEXTLENS_2026-09-30-v03.md)에 기준과 한계를 적었습니다.
