# ContextLens 분석 작업 화면 v06

`MASTER.md`의 차분한 색과 글자 중심 원칙을 적용한다. 이 화면은 뉴스레터 구독 페이지가 아닌 분석 작업 공간이므로 전환형 히어로·구독 문구는 적용하지 않는다.

- 흐름: 원문, 반응, 제안, 댓글, 판단, 검증의 여섯 화면. 결과 상단의 범위 요약은 모든 화면에 남긴다.
- 사실, 자동 분류, 해석 후보, 실험 제안을 제목과 짧은 설명으로 구분한다. 숫자는 표본의 범위를 함께 보여 준다.
- 넓은 화면에서는 판단 화면의 고객 정의 옆에 메모를 둔다. 1050px 이하에서는 고객 정의와 메모를 세로로 놓는다.
- 댓글의 수동 판단은 접어 두고 필요할 때만 펼친다. 자동 라벨과 수정 라벨을 동시에 보여 주며 근거·반례 표시를 구분한다.
- 검증 화면은 가설, 실제 변경, 지표, 전후 관찰, 다른 설명을 분리한다. 수집 시점 비교 문구에서 인과관계를 암시하지 않는다.
- 소개글, 자동 추출 문장, 표본, 언어, 욕구별 근거를 사용자가 펼쳐 볼 수 있게 한다. 중요한 상태와 검토 필요 건수는 처음부터 보인다.
- 한 번에 표시되는 댓글은 12개로 제한하고, 필터를 바꾸면 첫 12개부터 다시 보여 준다.
- 본문 16px, 보조 설명 14px, 상태 12px 이상을 기준으로 하며, 키보드 초점 표시와 동작 감소 설정을 유지한다.
