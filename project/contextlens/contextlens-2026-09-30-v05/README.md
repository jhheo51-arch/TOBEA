# ContextLens v05

원문 맥락, 댓글 표본, 시청자 욕구 후보, 다음 제공물을 읽으며 내 판단을 기록하는 로컬 분석 도구입니다.

## 이번 화면 개선

- 결과를 원문·반응·제안·댓글·메모의 다섯 화면으로 나눴습니다. 위 버튼을 누르면 선택한 내용만 표시됩니다.
- 욕구 후보는 제목과 관련 댓글 수부터 보여 주고, 누르면 원하는 것·다음 제공물·근거가 열립니다.
- 반복 표현, 표본 구성, 언어 범위, 분석 한계도 눌러 자세히 볼 수 있습니다.
- 댓글은 처음 12개만 표시하며, 더 보기를 눌러 12개씩 읽습니다.
- 넓은 화면에서는 메모를 오른쪽에 두고, 좁은 화면에서는 메모 버튼으로 엽니다.
- 분석을 마치면 입력 화면을 접어 결과에 집중하고, `새 분석`으로 다시 엽니다.
- 이전 버전과 같은 브라우저 저장 키를 사용하므로 기존 메모를 불러올 수 있습니다.

## 실행

이 폴더의 `실행하기.cmd`를 열거나, 가상환경에서 `python app.py`를 실행한 뒤 `http://127.0.0.1:8766/`을 여세요. 필요한 패키지는 `requirements.txt`에 있습니다.

## 해석 주의

자동 자막은 오인식될 수 있습니다. 욕구 카드의 수치는 수집한 댓글에서 보인 표현 수이며 전체 시청자 비율이나 만족도를 뜻하지 않습니다. 자동 분류하지 못한 언어 댓글은 원문을 직접 확인하세요.
