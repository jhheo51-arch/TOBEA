# ContextLens v05 — 필요한 내용만 열어 보는 분석 화면

## 문제

v04는 화면 크기를 좁혀도 원문·반응·표본·욕구 카드·댓글 40개·메모가 한 페이지로 이어졌다. 특히 모바일에서는 판단 메모까지 내려가는 거리가 길었다.

## 목표

첫 화면에서 자료의 범위를 파악하고, 원하는 분석 구역을 한 번 눌러 이동한다. 세부 근거는 해당 구역 안에서 펼쳐 본다.

## 구현

- 다섯 개 화면: 원문, 반응, 제안, 댓글, 메모. 선택한 화면만 표시한다.
- 결과 상단의 원문 상태·수집 건수·직접 검토 건수는 공통으로 표시한다.
- 반응 화면에서는 반복 표현·최신순/인기순 표본·언어 범위를 펼쳐 본다.
- 제안 화면에서는 욕구 카드마다 제목과 관련 건수를 먼저 보고, 눌러 해석·제공물·지표·근거 댓글을 확인한다.
- 댓글 화면은 필터와 첫 12개를 보여 주고 12개씩 더 읽는다.
- 넓은 웹 화면은 메모를 오른쪽에 유지하고, 좁은 화면은 메모 버튼으로 연다.
- 이전 버전의 메모 저장 키와 자료 저장 기능은 유지한다.
- 분석이 끝나면 입력 화면을 접고, `새 분석`으로 다시 연다. 현재 분석 제목은 모든 화면 상단에 남긴다.

## 확인 기준

- 원문, 반응, 제안, 댓글, 메모 버튼을 눌렀을 때 각 화면이 바뀌고 메모가 복원된다.
- 댓글 필터를 바꾸면 표시 수가 12개부터 시작한다.
- 휴대전화 너비에서 페이지 자체의 가로 넘침이 없고 다섯 버튼이 모두 보인다.
- 화면을 접어도 자동 분석의 한계와 원문 근거에 접근할 수 있다.
