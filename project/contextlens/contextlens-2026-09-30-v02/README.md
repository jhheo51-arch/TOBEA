# ContextLens v02

유튜브 영상·뉴스 링크를 넣어 원문과 댓글을 함께 살피는 개인 CX 분석 도구입니다. v01은 그대로 두고, 이번 버전은 댓글 표본 비교와 **시청자가 원하는 것 / 다음에 제공할 것**을 추가했습니다.

## 실행

Windows에서 [실행하기.cmd](./실행하기.cmd)를 두 번 클릭합니다. 첫 실행에는 Python 3과 인터넷 연결이 필요합니다. 브라우저가 자동으로 열리지 않으면 주소창에 `http://127.0.0.1:8766/`을 입력합니다. 실행 창을 닫으면 도구가 종료됩니다. `127.0.0.1`은 현재 컴퓨터의 주소입니다.

## 사용

1. 공개 영상·기사 URL을 넣고 **맥락부터 분석하기**를 누릅니다.
2. 원문 근거와 최신순·인기순 표본 수를 확인합니다.
3. 각 카드에서 댓글 근거 → 원하는 것의 해석 → 제공할 것의 제안 → 확인 방법을 읽습니다. **근거 댓글**에서 정렬별 필터와 더 보기로 원문 전체를 확인합니다.
4. 오른쪽 **내 판단 남기기**에 직접 확인한 내용과 반례를 적습니다. 같은 브라우저·같은 URL에서 자동 복원됩니다. **요약 저장**은 Markdown 문서, **자료 저장**은 댓글을 포함한 JSON 파일을 내려받습니다.

## 범위와 보관

- 유튜브: 최신순·인기순 각각 최상위 댓글 최대 100개. ID 중복 제거. 자막 접근이 안 되면 이를 표시합니다. 화면·음성을 직접 시청·분석하지는 않습니다.
- 뉴스: 공개 HTML 본문과 접근 가능한 공개 댓글. 동적 로딩·로그인 댓글은 가져오지 못할 수 있습니다.
- 메모는 브라우저의 로컬 저장소에만 자동 저장됩니다. 브라우저 데이터 삭제 또는 다른 기기로 이동할 때는 저장 파일을 백업해 주세요. 내려받은 JSON에는 공개 댓글 원문이 포함됩니다.
- 댓글 규칙은 욕구·문제의 **후보**만 알려줍니다. 전체 시청자 비율이나 개선 효과로 해석하지 않습니다.
