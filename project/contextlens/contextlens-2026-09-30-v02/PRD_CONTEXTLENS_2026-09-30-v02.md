# ContextLens v02 기획서

## 목표

공개 유튜브 영상 한 편을 출발점으로 **원문 맥락 → 댓글 표본 → 시청자가 원하는 것 → 다음에 제공할 것 → 검증 방법**을 한 화면에서 검토합니다. 사용자가 영상을 직접 보고 자신의 판단을 기록하며, 여러 사례를 쌓아 CX 기획과 데이터 해석 역량을 보여줄 수 있게 합니다. 뉴스 링크도 기존의 원문·댓글 분석 흐름을 지원합니다.

## 풀려는 문제

v01에서는 메모가 화면을 떠나면 사라졌고, 최신순 100개만 앱에서 분석했습니다. 별도 인기순 100개와 대조한 결과 중복이 적어 한 정렬만으로 반응을 대표하기 어려웠습니다. URL의 `?`를 질문으로 셌고, 노래 자동 자막의 가사 조각이 영상 내용 요약처럼 보였으며, 분석한 댓글 중 40개만 확인할 수 있었습니다. 반복 표현을 보여줘도 시청자의 원하는 것과 후속 제공물을 연결하지 못했습니다.

## 사용자와 성공 조건

- 사용자: 공개 콘텐츠를 사례로 혼자 CX 조사를 연습하는 기획자.
- 시작: 유튜브 또는 뉴스 URL 한 개를 입력.
- 성공: 수집 범위와 원문 근거를 먼저 확인하고, 댓글에서 추출한 욕구 후보마다 근거 댓글·정렬별 건수·제공할 것·확인할 지표를 볼 수 있음. 자신의 판단을 적은 뒤 다시 열어도 남아 있고, Markdown/JSON으로 내보낼 수 있음.
- 실측하지 않은 지표: 실제 시청자의 전체 비율, 제공물의 효과, 전환율. 제안 카드의 지표는 **향후 확인할 계획**입니다.

## 분석 흐름

1. 제목·설명·접근 가능한 자막 또는 기사 본문을 읽고, 영상 설명의 곡별 시간표·이벤트·상품 안내를 별도 사실로 표시합니다. 영상의 화면과 음성은 직접 해석하지 않습니다.
2. 유튜브 최상위 댓글을 최신순·인기순에서 각각 최대 100개 가져옵니다. ID 중복을 제거하고 두 정렬의 수집 수·겹침·고유 수를 보여줍니다. 정렬은 플랫폼이 정한 결과이며 무작위 추출이 아닙니다.
3. 고정 공지와 채널 운영자 댓글을 욕구 계산에서 제외합니다. 댓글 원문을 전부 볼 수 있으며 최신순/인기순으로 골라 확인합니다.
4. 반복되는 표현을 **관찰 사실**, ‘시청자가 원하는 것’을 **해석 후보**, ‘다음에 제공할 것’을 **실험 제안**으로 구분합니다. 각 후보에 해당 댓글 예시, 두 정렬의 건수, 확인 지표와 맥락상 주의를 붙입니다.
5. 사용자가 직접 원문에서 확인한 것, 반복 문제·반례, 개선 가설, 검증 방법을 기록합니다. 브라우저의 로컬 저장소에 자동 저장하고 같은 URL을 다시 분석하면 복원합니다. 원자료와 기록을 내보낼 수 있습니다.

## 첫 영상에서의 방향 판단

대상은 `[추석 특집] 제나의 트로트 메들리`입니다. 영상 설명에는 곡별 시간표와 상품·댓글 이벤트가 있습니다. 따라서 댓글의 노래 요청이 모두 순수한 수요라고 해석할 수 없습니다. 반복 청취·곡별 무대 반응·가족 시청·팬 응원·후속 곡 요청·상품 질문을 별도 흐름으로 봅니다.

우선 **다시 듣기 경로**를 시험할 가치가 있습니다. 여러 댓글이 출근 전, 가족과 함께, 반복 재생 상황을 직접 말합니다. 곡별 재생목록 또는 짧은 클립을 제공하고, 곡별 이동·재방문·본편 연결을 확인합니다. 다음으로 **원하는 후속 곡을 직접 선택하는 방식**을 시험합니다. 이 신호의 표본 건수는 적고 이벤트 영향을 받을 수 있어 곧바로 제작하기보다 요청 유형을 정리해 선택 의사를 확인합니다. 상품·이벤트는 설명의 종료 여부를 명확히 표시하는 정보 개선 후보입니다.

## 데이터와 한계

원문 제목·설명·자막, 댓글 ID·본문·작성 시각·좋아요·정렬 출처·공지 여부를 사용합니다. 개인 작성자 정보는 저장하지 않습니다. 자동 자막은 가사와 고유명사를 잘못 인식할 수 있습니다. 댓글의 표현 규칙은 욕구를 확정하지 않으며, 서로 다른 욕구가 한 댓글에 함께 나올 수 있습니다. 표본은 시각과 플랫폼 정렬에 따라 바뀝니다. 뉴스 댓글은 사이트가 공개한 범위만 수집하며, 유튜브용 욕구 카드는 뉴스에 적용하지 않습니다.

## 다음 검증

사용자는 카드의 댓글 근거를 읽고 반례를 적습니다. 실제 콘텐츠 운영 권한이 생긴다면 작은 제공물 하나를 시험해 전후의 곡별 이동·재방문·질문 댓글을 확인합니다. 데이터가 확보되지 않은 상태에서는 효과를 주장하지 않습니다.
