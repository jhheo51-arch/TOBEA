# JH 기획 v02 — 스크롤 없는 기획 작업실

2026-10-01. 사용자의 요청에 따라 `ui-ux-pro-max`로 디자인을 보완하고 긴 페이지 대신 항목·문서 쪽 이동을 사용합니다. AI 연결 없이 문제 정의·지표·문서를 작성하는 서비스입니다. v01 파일은 그대로 보존했습니다.

## 사용

현재 미리보기 주소는 `http://127.0.0.1:8784/`입니다. 같은 주소와 저장 이름을 유지하여 이전 브라우저 기록·확정본을 이어 사용합니다.

다시 실행해야 하면 이 폴더에서 아래 명령을 실행합니다.

```powershell
python -m http.server 8784 --bind 127.0.0.1
```

## 디자인과 화면 구성

- 짙은 청록색의 작업 메뉴, 밝은 종이색 배경, 차분한 초록과 구리색 강조, 로컬 Pretendard 글꼴.
- 첫 화면: 내 프로젝트/가상 예시 탭과 이전·다음 페이지. 작은 화면에서는 카드 한 개씩 표시.
- 작성 화면: 문제·방향·지표·문서 네 단계, 작성 항목 선택, 한 항목씩 입력, 고정된 이전·다음 버튼.
- 긴 입력: 내용 페이지로 나눠 읽고 편집. 앞·뒤 내용과 줄바꿈·이모지를 보존.
- 최종 문서: 실제 화면 높이에 맞춰 여러 쪽으로 표시. 이전·다음 쪽으로 전체 문서를 읽음.
- 확정본: 문서 버전 선택으로 열람·다운로드. 확정본 열람 상태에서는 다시 확정하는 버튼을 비활성화.
- 다운로드·인쇄에는 쪽별 화면이 아닌 전체 기획서 내용을 사용.
- 페이지·내부 패널의 스크롤을 사용하지 않음. 공간에 맞춰 내용과 목록을 나눔. 짧은 프로젝트 제목/카드 요약은 줄임 표시하며 전체 내용은 프로젝트 입력과 문서에서 확인 가능.

스킬의 단계별 진행 표시·피드백·간결한 기업용 화면 권고를 적용했습니다. 첫 디자인 검색이 결혼·행사 스타일로 잘못 연결되어 기업용 생산성 도구로 좁혀 재검색했습니다. 검색의 모든 색·서체를 그대로 적용하지 않고 기존 JH 브랜드와 한글 가독성을 기준으로 조정했습니다.

## 저장과 한계

이 브라우저의 저장 공간에 기록됩니다. 다른 기기로 자동 동기화되지 않습니다. 자료를 삭제하기 전에 기록 백업을 보관하세요. 백업 불러오기는 기존 프로젝트 번호를 덮어쓰지 않습니다.

최대 50개 프로젝트, 프로젝트별 확정본 30개, 항목별 10,000자, 복원 파일 10MB. 손상된 기존 기록은 덮어쓰지 않으며 새 저장을 중단하고 원본 백업을 안내합니다. 동시에 여러 탭에서 편집하는 공동 작업은 지원하지 않습니다.

작은 높이의 화면에서는 도움말과 장식 요소를 줄여 입력·이동을 우선 표시합니다. 실제 휴대전화 키보드·200% 확대·모든 화면 크기에서의 사용은 아직 검증하지 않았습니다.

## 확인 결과

```powershell
node --check app.js
node --check core.js
node --check examples.js
node check.cjs
```

기존 필수값·형식·안전한 표시·확정본 보존·백업 검사 통과. 긴 문자열의 분할 후 연결 시 원문과 정확히 같고, 쪽 사이 문자 누락·중복이 없는 검사 추가·통과.

브라우저 확인:

- 기존 커피 기획·확정본 정상 열람, 프로젝트·예시 목록 페이지 이동.
- 1280×800, 714×668, 375×812, 375×600, 375×375, 812×375 화면에서 주요 작성/문서 화면 높이와 넘침 확인. 처음 낮은 화면에서 발생한 문서와 브랜드 위치 문제를 발견해 수정.
- 모바일 커피 문서 10쪽 모두 문서 영역의 표시 높이와 내용 높이가 일치. 이전·다음 쪽 이동 정상.
- 긴 100줄의 연습 입력을 저장·새로고침 복원·쪽 이동·중간 쪽 편집. 내려받은 백업에서 수정한 내용과 남은 원문 93줄 확인. 기존 확정본 보존.
- 빈 기획 확정 시 미작성 항목으로 이동하고 입력 초점 표시.
- 교육문화 가상 예시 확정 후 해당 확정본 표시·버튼 잠금·다운로드 정상. 실제 내려받은 파일에서 네 문서 영역과 최종 안내 전체를 확인.
- 브라우저 오류·경고 로그 없음.

실제 고객 성과, 전문가 검토, AI 실행은 수행하지 않았습니다. 백업 복원은 코드 검사로 확인했으며 브라우저 파일 선택부터 복원까지의 전체 과정과 실제 인쇄/PDF 저장 완료는 미검증입니다.
