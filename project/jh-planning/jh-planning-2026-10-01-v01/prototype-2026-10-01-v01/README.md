# JH 기획 · 기획 작성 서비스 v01

다양한 산업의 프로젝트를 **문제 정의 → 방향과 선택 → 성공 지표 → 최종 문서**로 정리하는 웹 작업실입니다. 사용자가 직접 작성하며 AI 생성과 데이터 분석은 이번 범위에 포함하지 않습니다. 현재 기획 기준은 상위 폴더의 `PRD-2026-10-01-v04.md`입니다.

## 실행

이 폴더에서 다음 명령을 실행한 뒤 `http://127.0.0.1:8784/`를 엽니다.

```powershell
python -m http.server 8784 --bind 127.0.0.1
```

설치할 외부 라이브러리나 비밀 인증값이 없습니다. 글꼴도 같은 폴더에서 읽습니다.

## 처음 확인할 일

첫 화면 아래 **로컬 커피 구독의 첫 홍보** 가상 예시를 열고, **최종 문서**를 누르세요. 문제·선택 이유·지표가 하나의 기획서로 보이면 됩니다. 다음에는 새 프로젝트에 자신의 상황을 작성할 수 있습니다.

예시는 식음료·교육문화·기업 서비스 세 가지입니다. 모든 내용과 숫자는 창작 자료이며 실제 고객이나 홍보 성과가 아닙니다. 예시 열기는 새 프로젝트로 추가되며 기존 기록을 덮어쓰지 않습니다.

## 저장과 문서

- 작성 내용은 현재 브라우저에 저장됩니다. 다른 브라우저나 기기로 자동 연결되지 않으며 브라우저 자료 삭제 시 사라질 수 있습니다.
- 확정은 필수 입력·형식과 작성/수정 이유를 확인해 새 버전을 저장합니다. 실제 실행이나 성과 달성을 뜻하지 않습니다.
- 확정본은 당시 입력의 사본으로 보존하므로 초안을 바꿔도 이전 문서가 바뀌지 않습니다.
- 초안과 확정본은 HTML 파일(브라우저에서 읽는 문서)로 내려받습니다. 인쇄에서 PDF 저장을 선택할 수도 있습니다. 브라우저의 PDF 저장 화면은 운영 환경에 따라 다릅니다.
- 전체 기록 백업은 프로젝트와 확정본을 JSON 파일로 저장합니다. 백업 불러오기는 기존 프로젝트 번호를 건너뛰고 새 프로젝트만 추가합니다. 기록이 포함된 파일은 본인이 보관하세요.
- 프로젝트 최대 50개, 프로젝트별 확정본 최대 30개, 복원 파일 최대 10MB입니다. 저장 실패 시 성공으로 표시하지 않으며 백업을 안내합니다.
- 손상된 기존 자료는 덮어쓰지 않고 새 저장을 중단합니다. 원본 백업을 먼저 보존하세요.
- 동시에 여러 탭에서 편집하는 공동 작업 기능은 없습니다. 한 탭에서 작성하는 것을 권장합니다.

## 확인한 범위

```powershell
node --check app.js
node --check core.js
node check.cjs
```

검사 통과: 필수 항목·후보 선택, 현재값 미확인/0 구분, 음수·백분율 범위·잘못된 날짜와 날짜 역전, 입력의 안전한 문자 표시, 확정본과 초안 분리, 손상·중복 백업 차단, 백업 복원 시 안전한 문서 재생성.

실제 브라우저 확인: 가상 프로젝트 생성, 네 단계 이동, 문서 확정, 메시지 수정, 새로고침 복원, 빈 기획 확정 차단과 해당 입력 위치 이동, 101% 목표 차단, 확정본 다운로드. 다운로드 파일에 확정본 표시·원래 메시지가 있고 나중에 수정한 메시지가 없는 것을 파일 내용으로 확인했습니다.

375×812와 812×375 화면에서 가로 넘침 없음과 모바일 지표 입력·백업 버튼 노출을 확인했습니다. 브라우저 오류 로그 없음, 로컬 글꼴 응답 정상 확인.

아직 확인하지 않음: 실제 고객 체험·수요·홍보 효과, 실제 휴대전화, 브라우저의 인쇄/PDF 저장 완료, 브라우저 파일 선택을 통한 백업 복원 전체 과정, 저장 공간 부족의 실제 브라우저 시험. 백업 복원의 형식·보존 규칙은 코드 검사로 확인했습니다.

확인 중 다운로드 완료 알림 도구가 시간 초과되었지만 실제 파일은 다운로드 폴더에서 발견해 내용을 검증했습니다. 프로그램의 AI 작업·외부 게시·공개 저장소 업로드는 실행하지 않았습니다.
