# JH 기획 PRD v04 — AI 적용 전 기획 서비스

작성일: 2026-10-01. 사용자의 최신 요청에 따라 v03의 실제 AI 연결과 데이터 분석을 이번 구현에서 제외한다. 기존 기획서는 보존한다.

## 이번 목표

다양한 산업에서 사용할 수 있는 기획 작성 서비스. 중심 질문은 ‘무엇을 왜 해야 하나?’이며 문제 정의·지표·문서로 답을 정리한다. 사용자가 직접 내용을 작성하며 자동으로 정리한 문서는 AI 결과로 표시하지 않는다.

## 핵심 흐름

내 프로젝트 → 문제 정의 → 실행 후보와 선택 이유 → 성공 지표 → 문서 미리보기 → 기획서 확정·버전 보존 → 다운로드.

- 문제 정의: 프로젝트·선택적 산업, 대상, 문제, 중요성, 사실·출처, 가정, 목표.
- 방향과 선택: 후보 최대 3개, 후보별 실행·근거/제약, 선택 이유, 제외 범위, 메시지, 채널, 첫 행동. 후보 한 개부터 시작할 수 있으며 이름과 실행이 있는 후보 선택은 확정 시 필수.
- 성공 지표: 이름, 단위, 현재값(미측정은 빈칸), 목표값, 계산·포함/제외 기준, 자료 출처, 측정 기간, 유지·수정 기준.
- 문서: 입력을 안전하게 정리한 미리보기, 작성·수정 이유, 초안 HTML 다운로드, 인쇄/PDF, 확정 문서 버전별 다운로드.

## 완료 기준

- 산업 선택을 필수로 강제하지 않는다.
- 가상 예시는 식음료·교육문화·기업 서비스로 구분하며 실제 고객·성과로 표시하지 않는다.
- 필수 입력·형식 확인을 기획 타당성이나 실제 효과 검증으로 표시하지 않는다.
- 현재값 미확인과 명시한 0을 구분한다. 음수·100을 넘는 백분율·날짜 역전을 차단한다.
- 필수 항목 누락 시 초안은 내려받을 수 있으나 확정본은 만들지 않는다.
- 내용 수정과 확정본 보존을 분리한다. 확정본은 이전 입력의 사본으로 유지한다.
- 브라우저 저장·새로고침 복원·전체 백업/복원을 제공한다. 복원은 기존 번호를 덮어쓰지 않는다.
- 저장 실패는 성공으로 표시하지 않는다. 손상된 기존 자료는 덮어쓰지 않고 원본 백업을 안내한다.
- 모바일 한 열 배치, 입력 이름과 도움말, 키보드 초점, 인쇄 화면을 제공한다.

## 범위와 한계

기기 간 자동 연결·로그인·실제 AI 호출·자료 분석·외부 게시·광고 집행·공개 업로드는 이번 범위에 없다. 브라우저 자료 삭제 시 기록을 잃을 수 있으므로 백업을 제공한다. 프로젝트는 최대 50개, 프로젝트별 확정본은 최대 30개다. 실제 사용자 수요와 홍보 성과는 미검증이다.

오른쪽 이미지의 최종 과제 목표는 유지한다. 이번 단계는 AI가 수행할 기획 절차를 실제 서비스에서 먼저 확인하는 단계이며, AI 에이전트의 자율 작업·검증 완료를 주장하지 않는다. 공개 제출 준비는 후속 단계다.
