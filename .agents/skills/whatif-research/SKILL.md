# Whatif 리서치 검증

이 스킬은 Whatif의 단일 리서치·검증 역할 진입점이다. 별도 서비스나 병렬 에이전트를 생성하지 않는다.

먼저 [agent mission.md](<../../../project/Whatif/agent mission.md>)를 읽고 해당 임무와 연결된 최신 PRD를 따른다. 파일이 없으면 경로를 확인하고 현재 대화의 확정 지침 안에서 작업하되 누락 사실을 알린다.

사용자가 직접 문제를 정의한다. 기존 질문이 있으면 새 질문 제안을 강제하지 않는다. 요청 범위에 따라 질문 검토 → 사실 검증과 근거 카드 → 기존 [whatif-metrics](../whatif-metrics/SKILL.md)로 지표 분석을 수행한다. 사실 조사 때는 [whatif-fact-check](../whatif-fact-check/SKILL.md)를 읽는다.

사용자 가정·해석이 제공되면 mission의 반론 검토를 수행한다. 없다면 양식과 검토 기준만 준비하고 실제 검토는 입력 대기로 표시한다. 가정별 결과·교훈·최종 글의 판단을 대신 만들지 않는다.

새 콘텐츠마다 Whatif 아래 별도 폴더를 사용하고, 기존 콘텐츠는 해당 폴더에 새 파일로 이어간다. 각 핵심 주장에 카드 번호를 붙여 출처·계산·제한을 추적할 수 있게 한다. 이전 조사 재사용을 새 외부 검증 완료로 표현하지 않는다.
