# FanBridge 데이터·API 조사

- 확인일: 2026-09-30
- 범위: 공식 서비스 소개·개발 문서 확인. 인증 키를 이용한 실제 데이터 요청·계약·가입·결제는 수행하지 않음.
- API는 외부 서비스에서 프로그램으로 데이터를 요청하는 연결 통로다. 존재 확인과 우리 계정으로 2025·2026년 자료를 확보하는 것은 다른 단계다.

## 1. 핵심 결론

팬 경험 자료의 발견·접근 API와 경기·날씨 맥락 API는 존재한다. 다만 일반 공개 API로 구단 고객별 구매·상담·환불 이력을 받을 수 있다는 근거는 확인하지 못했다. 첫 제품은 적법하게 확보한 후기·질문과 동의받은 팬 조사, 공식 정책을 중심으로 만들고 스포츠 API를 선택적으로 연결한다.

| 제공처 | 확인한 제공 범위 | 2025·2026 자료 판단 | 인증·비용 판단 | 추천 |
|---|---|---|---|---|
| YouTube Data API v3 | 영상 검색·공개 댓글 스레드·답글 조회 | 현재 접근 가능한 과거 자료 후보. 두 연도의 완전한 자료나 과거 상태 복원 아님 | 인증 정보·사용량 할당 필요. 실제 계정 미확인 | 조건부 참고 경로 |
| 네이버 검색 API | 블로그 검색 제목·요약·링크·작성일 | 작성일로 확보 결과 분류 가능. 연도별 전수 검색 보장 없음 | 앱 등록과 Client ID/Secret 필요. 계정 할당량 미확인 | 후기 발견 보조 |
| API-Sports API-BASEBALL | 공식 지원 목록에 KBO·퓨처스 포함 | 두 시즌별 실제 응답·필드·요금제 범위 미검증 | 공식 소개에 API당 하루 100회 무료 플랜. 과거 시즌 접근 조건은 별도 확인 | 경기 맥락 선택 연결 |
| Sportradar Global Baseball v2 | KBO 포함, 시즌·경기·과거 결과 | KBO 두 시즌의 제공 범위·계정 권한 미검증 | API 키·상품 권한 필요, 프로젝트 가격 미확인 | 상용 대안 |
| 기상청 ASOS 일자료 | 일별 기온·강수 등 과거 관측 | 문서의 역사적 범위에 두 연도 포함. 관측소·날짜별 누락은 응답으로 확인 필요 | 포털 문서상 무료, 서비스 인증키 필요 | 필요할 때 연결 |
| KBO 공식 웹페이지 | 2025 역대 관중 표·2026 일자별 관중 자료·일정 화면 | 관련 연도 자료 공개 확인. 모든 날짜의 완전성은 아직 검사하지 않음 | 일반 공개 개발자 API 문서는 이번 조사에서 못 찾음 | 공식 검증 자료 |

## 2. YouTube: 접근 가능하지만 자동 분석의 조건을 먼저 확인

공식 [commentThreads.list](https://developers.google.com/youtube/v3/docs/commentThreads/list) 문서에서 videoId, 최대 100건, 페이지 이동, time/relevance 정렬을 확인했다. relevance는 관련성 정렬이며 좋아요순으로 단정하지 않는다. 포함된 replies만으로 전체 답글이라고 할 수 없으므로 [comments.list](https://developers.google.com/youtube/v3/docs/comments/list)로 답글을 별도 조회한다.

[search.list](https://developers.google.com/youtube/v3/docs/search/list)의 publishedAfter/publishedBefore는 영상 등 검색 대상의 게시 시각 필터다. 댓글에는 [comments 리소스](https://developers.google.com/youtube/v3/docs/comments)의 publishedAt·updatedAt을 확인해 연도를 적용해야 한다. 예전 영상에 올해 달린 댓글을 작년 댓글로 분류하지 않는다. 최신·관련성 일부 표본만으로 과거 댓글 전체를 확보했다고 쓰지 않는다.

현재 [개발자 정책 III.E.4, III.E.5 및 III.L](https://developers.google.com/youtube/terms/developer-policies)에는 비승인 자료의 제한적 보관·30일 이내 갱신 또는 삭제, API 자료로 새 데이터·지표 생성 제한, 별도 허용을 받은 분석 용도의 추가 정책이 명시되어 있다. 따라서 댓글 자동 분류·점수·연도별 파생 지표 생성과 과거 원문 영구 보관을 기본 허용으로 가정하지 않는다. 우리 사용 사례의 허용 범위를 확인하기 전에는 제품 분석 연결을 비활성화한다. 허용이 확인되지 않으면 동의받은 팬 조사 등으로 대체하며 비공식 수집으로 우회하지 않는다.

연결 전 시험: 승인·할당량·보관 조건 확인 → 댓글 허용 영상 하나 → 한 페이지 응답 → 작성일·중복·답글·오류 확인. commentsDisabled·403·404·할당량 초과는 0건과 구별한다. 일반 API는 삭제되거나 비공개가 된 과거 자료를 복원하는 서비스가 아니다.

## 3. 네이버: 후기 검색 결과를 발견하는 용도

공식 [블로그 검색 문서](https://developers.naver.com/docs/serviceapi/search/blog/blog.md)에서 검색 결과의 제목·요약·링크·postdate와 display 최대 100, start 최대 1000, sim/date 정렬을 확인했다. 블로그 전체 본문·댓글을 받는 API로 설명하지 않는다. 검색어에 연도를 넣어도 정확한 연도 필터가 되지는 않으므로 반환된 작성일을 따로 확인한다.

먼저 두 연도 동일 검색어·정렬·페이지 규칙으로 후보를 찾는다. 원문은 접근·이용 조건을 확인한 범위에서 사람이 읽고, 경험 날짜·맥락·짧은 근거를 기록한다. 요약만 읽었다면 원문을 확인한 것으로 표시하지 않는다. 검색 순위·오래된 글 누락으로 표본이 달라질 수 있어 전체 팬 비율을 계산하지 않는다.

연결 전 시험: 등록 앱의 검색 사용 권한 → 구단·주제 검색 한 건 → 두 연도의 postdate 접근 가능성 → 중복 URL·요약 누락·검색 깊이 제한 확인. 부족하면 동의받은 조사나 다른 허용 출처로 보완한다.

## 4. 경기 API: KBO 지원 확인과 과거 시즌 보장은 구분

- API-Sports: [공식 Baseball 지원 목록](https://api-sports.io/sports/baseball)에 KBO와 KBO Futures League가 있고, [공식 홈페이지](https://api-sports.io/)는 하루 API당 100회 무료 플랜을 안내한다. [Baseball v1 문서](https://api-sports.io/documentation/baseball/v1)는 주소를 확인했으나 이번 텍스트 읽기에서 상세 본문이 반환되지 않았다. 2025·2026년 무료 접근, 상태 코드·갱신 주기·경기 취소 정보의 완전성은 확인하지 못했다.
- Sportradar: [Global Baseball v2 공식 개요](https://developer.sportradar.com/baseball/reference/global-baseball-overview)는 KBO 및 시즌·팀·경기·과거 결과 제공을 설명한다. 실제 상품별 범위는 Coverage Matrix와 계정 권한으로 확인해야 한다. 가격을 임의 산정하지 않는다.

공통 연결 전 시험: 시즌 목록에서 2025·2026 존재 확인 → 각 시즌 표본 경기 조회 → 홈·원정·구장·경기 날짜·상태·시간대 확인 → 가능한 취소·연기 사례와 공식 기록 대조 → 응답 누락·페이지·호출 제한 검사. 실제 반환 필드만 데이터 구조에 매핑한다. 경기일이 확인되지 않은 후기에 임의 경기 ID를 붙이지 않는다. 날짜·홈구단·상대팀·구장·더블헤더 구분 등이 일치하지 않으면 연결 미확정으로 남긴다.

실제 고객센터 기록이나 팬 구매·환불 이력을 제공하는 API로 소개하지 않는다. 서비스 구현은 비용·과거 제공 범위가 확인되지 않은 스포츠 API에 의존하지 않게 한다.

## 5. 기상청: 과거 날씨 맥락

[공공데이터포털 ASOS 일자료 공식 페이지](https://www.data.go.kr/data/15059093/openapi.do)는 과거 기온·강수 등, 지점별로 다른 역사적 관측 범위, 무료·출처표시 조건을 안내한다. 2025·2026년을 조회할 수 있는 서비스 범위지만 실제 지점·날짜의 완전한 응답은 아직 확인하지 않았다.

연결 전 시험: 활용 신청·서비스 인증키 → 구장과 관측소 연결 근거 → 각 연도 표본 날짜 → 누락값·단위·한국 날짜 확인. 강수량 0과 누락을 구분한다. 인근 관측소 값이 경기장 현장 날씨와 같다고 단정하지 않는다. 일자료에는 경기 시각의 세부 날씨가 없으므로 필요한 경우 시간 자료를 별도로 검토한다. 날씨만으로 경기 취소·환불을 판단하지 않는다.

## 6. KBO: 공식 웹자료와 공개 API 구분

[역대 관중 현황](https://koreabaseball.com/Record/Crowd/History.aspx)에서 2025년 표를, [일자별 관중 현황](https://www.koreabaseball.com/Record/Crowd/GraphDaily.aspx)에서 2026년 기록을 확인했다. [경기 일정·결과](https://www.koreabaseball.com/Schedule/Schedule.aspx)는 날짜·시간·경기·구장·비고 항목을 가진 공식 화면이지만 이번 텍스트 읽기에서는 경기 행이 반환되지 않았다. 전체 일정 수집이 가능하다고 주장하지 않는다.

KBO 공식 사이트와 공공데이터포털 검색에서 일반 개발자가 사용할 수 있는 KBO 경기·팬 문의 공개 API 문서는 확인하지 못했다. 이는 API가 없다는 확정이 아니다. 웹페이지 내부 요청 주소를 공식 지원 API라고 부르지 않는다. 웹자료의 프로그램 수집·재배포는 이용 조건을 확인한 뒤 결정하며, 처음에는 필요한 공식 자료의 수동 확인으로도 진행한다.

## 7. 권장 연결 순서와 실행 상태

1. 이용 조건을 확인한 공개 경험·공식 정책으로 두 연도의 자료 적합성을 점검한다.
2. 네이버 검색은 후기 발견에 활용하고, 동의받은 팬 인터뷰로 문제를 검증한다.
3. 날짜 연결이 필요한 주제를 선택했을 때만 기상청·경기 API를 추가한다.
4. YouTube 분석은 허용 범위를 확인한 경우에만 채택한다.

현재 완료: API·자료 제공처의 문서 조사, 역할·한계·연결 전 시험 정의.

현재 미완료: API 키 발급, 인증 호출, 2025·2026년 실제 표본 확보·분석, 구단 과거 정책 수집, 실제 팬 조사. 가입·로그인·유료 결제는 실행하지 않았다.
